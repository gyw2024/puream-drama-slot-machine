# 0.13.45 正式版

本版针对客户升级后的图片裂图、人物身份资产错用、复杂剧本识别和一键/分步续跑稳定性做了根因修复。

## 核心修复

- 本地图片、视频和音频不再依赖持久化 `file:///` 地址，统一由受控的 `puream-asset://` 协议按真实文件路径动态读取；只允许访问当前工作台数据目录内的文件。
- 人物合板、三视图和介绍图共用唯一的当前身份指针。用户最后上传或明确选择的身份资产会同步用于人物卡片、分镜参考和后续视频，不再被旧合板覆盖。
- 上传剧本增加本地格式识别与确定性对白账本，覆盖生产稿、普通对白稿、时间码稿、中文影视剧本、Fountain/英文影视剧本和 JSON；支持角色名独占一行及括号表演提示。
- “人物介绍 / 故事梗概 / 正式剧情”在进入拆镜前完成物理分流，元数据不进入成片时间线。
- 一键全流程按真实缺失依赖续跑；分步制作只运行用户点选的当前阶段；同项目重复点击仍由运行锁拦截，失败历史与断点保留。

## 发布门槛

- 全量自动回归必须通过。
- 打包版和安装版必须使用真实本地图片验证 `complete === true` 且 `naturalWidth > 0`，不再以“页面存在 img 标签”代替图片可见。
- 7 个主阶段、7 个主要弹窗、5 组窗口/缩放矩阵、严重级无障碍问题与横向溢出均为阻断项。
- 验收不提交任何付费图片或视频任务。
