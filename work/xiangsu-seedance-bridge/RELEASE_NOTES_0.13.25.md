# 纯梦短剧老虎机 0.13.25

本版把用户原稿、用户提示词和费用回执统一为可追溯的生产合同。

- 新增“秒级分镜成片稿”：先提炼剧情简介，再按幕、5–15 秒分镜、秒级子镜、对白汇总、音效和负向提示编写；AI 一键写作与用户上传均可使用。
- 用户上传此类成片稿时，本地直接识别幕、分镜、人物、场景、道具、对白与原始时长，不重复调用文本模型；不同视频供应商会按单镜时长上限拆分，但总时长和逐句对白不变。
- 剧本、资产、分镜图和分镜视频均支持从 0 批量上传用户提示词；实体尚未生成时也可先上传，后续会按项目、人物、场景和镜号自动匹配。系统提示词建议可单独下载，不覆盖用户内容。
- 场景资产改为一张 16:9 的 2×2 四视图参考板，固定同一空间的正向、反向、左 45 度和右 45 度；分镜与视频只选择匹配机位的一格，禁止把参考板渲染进成片。
- 文案费用不再把成功但待回执的长文本显示成 0：上游有实际回执时显示实扣；尚待结算时按 token 单独显示“待实扣·预估”，估算不计入实际合计，也不会上报为真实扣费。
- 文本、图片和视频任务取消累计客户端时限；五分钟仅作为写作性能目标，不再作为自动中止条件。
- 用户上传普通剧本的拆镜改为输入/输出双预算分块：单次最多 5 个视频单元、长 JSON 最多 3 路并发；每完成一块立即写入项目断点。网络中断或某块格式异常后，继续任务只复用同一请求 ID 补未完成块，不再让整部剧本和已扣费块重跑。
- 拆镜现在纳入项目级运行互斥与暂停/停止控制；同一项目不能重复启动拆镜，失败前已完成的后台请求会全部落盘后再呈现失败，避免界面停了但请求仍在后台游离。
- 修复“审核蓝图关闭后云端英文提示词仍进入 2/4 重编译”的旁路：总开关或视频审核关闭时，每镜只编译一次，跳过语言/创作质量校验、自动打回和自动返修；已有编译稿直接本地归一化复用。最终组装只保留接口必需结构，并对非对白中文泄漏做本地清理，不再重新调用文本模型。
- 继续保持逐句对白、说话人、听者、语气、表情、身体动作、商品原图与八种生产模式矩阵的一致性合同。

验证：本地自动化回归 95 项全部通过；最终二进制已通过 5 组窗口/缩放矩阵、全部阶段与弹窗、无障碍、并发切换/删除恢复、默认云端与 OSS 持久化的打包态审查，并已在 Windows 本机覆盖安装后通过安装态启动审查；审查过程未提交任何付费生成任务。
