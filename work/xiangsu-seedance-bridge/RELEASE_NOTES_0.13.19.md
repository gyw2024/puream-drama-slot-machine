# 0.13.19 修复说明

本版本针对 0.13.18 的全流程关联逻辑进行了源代码级修复和故障注入审查。

## 关键修复

- 不同项目使用不可变的视频桥接配置并可并行运行；同一项目的重叠操作会被明确拒绝。
- 项目存储改为原子写入、有效备份和并发三方合并；损坏索引可重建，无法恢复的项目仍保留可见记录。
- 项目删除进入可恢复回收区，桌面端提供历史项目恢复入口。
- 一键视频不会被前一阶段自动触发；启动恢复只查询已提交任务，不创建新任务。
- 逐秒合图模式彻底跳过尾帧生成、等待和质量校验。
- 云端视频提示词与本地像塑提示词独立编译；云端对白镜头硬性绑定说话人、听话人、情绪语气、原句、反应和声音。
- 用户手动提示词原样保存和提交；审核蓝图总开关关闭后不执行创作质量拦截。
- 剧本、提示词、图片、视频、音频和远程下载均增加明确体积、解码、超时与路径边界。
- 每个生产阶段补齐手动输入/上传入口，独立资产库支持图片、视频和音频。
- 最终成片保留版本历史；独立资产入库、配音提取等后处理失败会显示警告而不丢失主结果。
- 五分钟剧本路径减少串行模型调用，并行生成正式单元；完成后直接进入资产阶段。
- 修复自有阿里云 OSS 设置被强制清空的问题：用户可明确选择托管或自有 OSS，AccessKey、Bucket、Endpoint 与签名有效期会安全持久化；界面同时明确区分“参考素材直传”与“生成结果本地下载”。

## 验证边界

- 自动测试和打包态审查不会调用付费生成接口。
- 五分钟为应用侧调度目标，第三方文本模型自身超时或拥塞仍可能使总耗时超过五分钟。
- Windows 安装包在没有代码签名证书的环境中只能生成未签名包；SHA-256 可验证文件完整性，但不能替代 Authenticode 发布者签名。
