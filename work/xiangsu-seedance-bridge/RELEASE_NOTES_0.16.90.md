## 修复

- 文本、图片、视频生成与轮询统一使用至少 20 分钟的生产时限；模型流持续返回有效内容时继续等待，不再被同长度总计时器误杀。
- 上传剧本分析、AI 改稿、选题、剧本、资产提示词、分镜合图提示词、分镜视频提示词均使用统一的 20 分钟窗口。
- 媒体导入、图片兼容转换、人脸网格、FFmpeg 分析/拼接/转码和视频元数据清理同步提升到至少 20 分钟。
- 本地像塑桥在提交前最多等待至少 20 分钟；无 taskId 视频提交保留 30 分钟恢复余量；旧页面持续查询同一远端任务，不因本地 20 分钟墙钟停止。
- 安全恢复只发生在没有部分文本、没有计费/使用量回执、没有完成信号时，并复用同一逻辑会话与幂等键。
- JSON 仅定向续补缺失后缀，默认最多两次；已有结果、回执或完成信号时不整单重写。
- 选题返回 1-9 个时直接展示，有几个显示几个；未闭合 JSON 中已经完整的选题也会立即恢复。
- Gemini 日配额、分钟配额及配额 ID 能贯穿错误包装；硬配额立即停止，普通限流按生产窗口有界等待。
- 简易模式验收矩阵与当前产品一致：只包含资产、分镜合图、分镜视频及辅助面板，不出现文本模型配置；首次进入展示三步说明。
