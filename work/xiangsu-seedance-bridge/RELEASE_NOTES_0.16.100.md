# 纯梦短剧老虎机 0.16.100

## 修复

- 管理员授权码在官网滚动发布后不再依赖某个临时内部端口；授权 sidecar 使用稳定官网业务入口，并仅对网络故障或 5xx 做受控故障转移。
- 登录与管理员角色心跳复验统一使用同一认证调用器，防止两条链路再次出现配置漂移。
- 保留安全边界：管理员只免设备绑定，不免套餐、到期、余额或官网共享并发；普通用户第二台设备仍会被服务端拒绝。
- 桌面端不再把“应用授权服务暂时不可达”显示成“模型授权无效”。应用授权、设备绑定、套餐、并发同步与模型 API 密钥错误按错误域分别提示。
- 提示词确认弹窗按人物、场景、物品/商品、分镜合图、分镜视频的自然编号稳定排序；卡片等宽等高，长内容在卡片内部滚动，英文执行稿均提供完整中文查看/编辑稿。
- “稍后确认”后主界面永久保留“查看并确认提示词”入口；中文修改会在确认时更新英文执行稿，翻译服务暂时不可达时也不会把流程卡死。
- 上传稿件先由 AI 做格式适配，再由结构解析器提取；格式适配被约束为不得改剧情、对白、动作、场景出现顺序。Markdown 加粗角色、叙述句引号对白、动作人物和场景别名均可识别。
- 修复人物抽卡把“待确认提示词”误当成“候选图片结果”的路由错误：首次点击只打开提示词确认，确认后自动恢复原始生图请求，只有收到真实候选结果才打开资产库。
- 结构化语气对象不再写成 `[object Object]`，人物对白的语气字段会被提取成可读文本。

- 客户 5 分钟 Markdown 稿实测识别 6 个人物、5 个唯一场景、6 次场景出现、50 句对白并生成 57 个自适应分镜；未提交付费媒体任务。
