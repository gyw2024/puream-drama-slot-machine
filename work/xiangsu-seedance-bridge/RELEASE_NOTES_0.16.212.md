# 0.16.212

素材存储位置统一控制工作台和两种模式的上传暂存目录，避免已迁到 D 盘后仍向 C 盘写入暂存素材。保存的位置损坏、磁盘或目录丢失时明确报错，保留原项目，不创建看似空白的替代工作台。已有安装保留原默认位置，新 Windows 安装检测到 D 盘时优先使用 D 盘；本机通过持久配置指定无限画布项目下的运行数据目录。

本机迁移采用独立本地备份、逐文件 SHA-256 恢复验证及旧路径目录联接。只对内容、扩展名及修改时间均相同的已完成、受管理素材做物理去重；保留项目、资产 ID 和全部引用路径。数据库、JSON、日志、暂存文件及独立备份不做硬链接。此次未更改生成模型、剧本逻辑或界面交互。
