# 纯梦短剧老虎机 v0.14.1

发布日期：2026-08-15

## 本次正式版解决的问题

- 后台并发成为唯一权威：图片、人物视频和分镜视频分别读取管理后台授权额度，不再经过本地 `2` 路上限二次截断；异常或缺失额度时停止新提交，避免假装按高并发运行。
- 生产态完全可见：生成中、排队、失败和已完成均在对应资产卡与右侧任务中显示，生成中的图片/视频不再表现为无反馈的空框。
- 六阶段状态按真实产物计算：只完成剧本时只标记第 1 阶段完成；资产运行时显示 `第 2/6 阶段 · 资产`，不再因为一次阶段调用结束而误报全流程完成。
- 分镜提示词编辑不再被轮询打断：实时状态刷新会保存并恢复展开项、弹窗、未保存文本、焦点和选区；逐秒合图、首尾帧和视频提示词均可持续编辑。
- 文案计费拆开显示：官网实际结算、等待官网回执、本地预估三种状态独立呈现；等待回执的估值不再混入“实际已结算”合计。补充解析嵌套官方计费回执。
- 本地图片改由受限 `puream-asset://` 协议读取，兼容中文、空格和保留字符路径，并限制在用户选择的数据根目录内，解决升级后资产图加载失败。
- 新增标准 MCP 控制入口，保持原界面和原流程不变。提供 33 个工具、3 个只读资源和 1 个完整短剧制作提示模板；付费工具必须显式传入 `confirm_billable: true`。
- Windows 打包版 MCP 使用透明 Node stdio 侧车，避免 Electron GUI 子系统吞掉 JSON-RPC 输出；可直接用安装后的 EXE 加 `--mcp-stdio` 连接。
- 保留并强化此前底层重构：任意剧本格式识别、场景账本、精确对白谱系、断点续作、稳定幂等提交、资产护照、统一纯色人物合板、无字幕/无背景音乐硬约束、可恢复项目历史、安装目录选择和数据保存位置迁移。

## 兼容与安全

- 正常双击启动路径和现有界面不变。
- MCP 与应用只通过带随机令牌的本机命名管道通信；不暴露 API Key、支付或授权修改能力。
- 旧项目、候选资产、失败历史、费用账本和远端待恢复记录均保留。
- 安装程序继续允许用户选择安装目录；软件设置内允许迁移数据保存位置，迁移时保留旧副本。
