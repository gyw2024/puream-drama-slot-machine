# 纯梦短剧老虎机 0.16.114

## 本地根修复版

- 剧本和商品流程完成后，在进入资产生成前统一弹出“确认后续全部生成提示词”总窗；人物、场景、物品/商品、分镜合图、分镜视频全部按实际生产顺序展示。
- 中文查看/编辑稿和英文执行稿均显示完整字符数并保留全文，不再压成一行、不再截到 500 字；长文本只在每张等高卡片内部滚动。
- 英文条目可展开查看当前完整执行稿；编辑中文后再确认，系统按完整中文重新编译执行稿。单条确认、一键确认和稍后确认后重新打开均保留原文。
- 单镜提示词编辑器同样显示完整中文稿，复制系统稿到自定义模式时不会再复制一份被截断的 500 字稿。
- 结构化语气、情绪、音量、语速、重音和呼吸不再显示为 `[object Object]`。
- 资产、分镜图和分镜视频三个批量入口都在工作流最内层执行同一确认门禁；未确认时不会先补资产依赖、申请并发或提交付费任务。
