# 0.16.215 写作与拆镜交接修复

完整正文已经生成，但自动生产入口在调用拆镜之前检查分镜，导致出现 `SCRIPT_NOT_MATERIALIZED`。现在先执行拆镜，再校验结果，失败时保留原始错误和已保存正文。

- 重试“生成并自动生产”时复用当前选题对应的已完成正文，不因分镜为空再次编剧。
- 新版逐场写作断点、审核修订及 15 分钟预算暂停接入续做；待修订正文不能跳过审核进入生产，也不会自动进入旧版整剧重写循环。
- 界面区分正在写作、正在拆镜、拆镜未完成、剧本待修订和阶段完成；写作运行期间正确保留暂停、停止控制。
- 整稿拆镜请求保留完整原文，只精简重复的对白、语气和估时字段；未改变完整性、说话人、动作或静默校验要求。
- Codex 纯文本 CLI 调用对可识别的本地 MCP 服务器使用单次禁用参数，避免每次写作重复启动工作台进程；不改动用户 Codex 配置，图片生成和 MCP 接管模式不变。
- 商品图观察纳入前期制作的同一个时间预算，避免先观察图片再额外计时。
