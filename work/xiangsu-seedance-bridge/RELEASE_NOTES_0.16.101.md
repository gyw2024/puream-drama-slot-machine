# 纯梦短剧老虎机 0.16.101

## 修复

- 分镜合图不再作为一张复合大图直接交给视频模型。系统会按合图声明的行列切成独立的 9:16 时间帧，并按对白与动作时间顺序绑定到视频提示词；人物、鞋子、走位等后续格不会再被第一格覆盖。
- 新生成的分镜合图使用与项目相同的画幅拓扑。9:16 项目的每个小格和整张画布都保持 9:16，避免旧式正方形 4×2 合图把单格拉成 1:2。
- 每句对白统一锁定稳定人物编号、说话人口型、说话人机位、对应音色和闭口听者；人物名称变化或双人同框时也不会交换 A/B 台词。
- “再抽一次”不再只信任可能已经失效的旧选中路径。旧文件被替换时会自动使用同一制作版本仍存在的候选，并重新生成独立分镜参考，不再误报缺少 9:16 分镜合图。
- 提示词确认页和分镜视频“查看 / 编辑提示词”窗口统一显示结构化纯中文编辑稿；英文供应商执行稿保留在内部，用户保存中文修改后再编译为上游执行稿。
- 提示词卡片继续按人物、场景、物品/商品、分镜合图、分镜视频及自然编号稳定排序；长内容只在各自卡片内部滚动，稍后确认后可从主界面固定入口重新打开。

## 验证

- 用户提供的 4×2 分镜合图被实际切成 8 张独立 360×640 时间帧，至少 6 个不同画面哈希，顺序为第 1 至第 8 格。
- 分镜比例、缺失旧候选后的重抽、A/B 说话人与口型/音色绑定、纯中文展示专项：4/4。
- 完整仓库自动回归：636/636，失败、取消、跳过均为 0。
- 提示词界面 7 组视口/缩放、等宽等高、顺序、内部滚动、稍后恢复、中文修改保存再打开、严重/致命无障碍问题和页面异常全部通过。
