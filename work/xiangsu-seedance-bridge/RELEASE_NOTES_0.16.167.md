# 纯梦短剧老虎机 0.16.167

## 智能粗剪

- 将原“最后合成”升级为“智能粗剪”：逐镜安全检测片头短促爆音、咂声或假起音，只在“短促有声后紧跟静音”的明确模式下同时裁剪画面与声音；纯静音表演不会被裁掉。
- 内置150种固定特效音，参考剪映常见使用语义整理为剧情强调、搞笑反应、转场、悬疑、动作、生活拟音、脚步衣料、环境与商品科技九类。
- Agent 根据场景、动作、情绪、反转和商品操作生成可解释 cue sheet；每镜最多3个音效，片头0.25秒为保护区，不生成新音频、不访问付费上游。
- “咚咚剧情强调”用于身份揭晓、权势登场、反转和打脸；搞笑弹簧、疑惑问号、翻车失败等用于喜剧反应；雨夜、道路、室内等环境音按场景匹配。
- 混音失败不会让用户卡死：自动保留已完成片头净音的无音效粗剪版，并在项目中记录原因。

## 可追溯与质量门禁

- 项目保存逐镜裁剪秒数、音效ID、命中原因、节目时间点、音量、混音结果与150音效库版本。
- 构建前强制校验音效数必须为150、ID和路径唯一、文件存在；回归测试进一步逐个完整解码全部150个OGG。
- 工作台直接显示“共裁除多少秒片头杂音、Agent匹配多少个音效”，并在1024×720、1440×900和1920×1080验证无横向溢出、无按钮截断、无严重可访问性问题。
