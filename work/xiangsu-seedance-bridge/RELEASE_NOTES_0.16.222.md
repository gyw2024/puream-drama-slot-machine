# 0.16.222 — 剧本审核修订入口恢复

修复剧本审核失败后，任务被错误标记为“远端待恢复”、审核错误码被清空、页面仍显示后台执行且没有修订入口的问题。

- 必须手动继续的失败保留原错误码，停止自动恢复；旧版已保存的审核断点也能显示修订入口。
- 剧本阶段展示“审核修订并复检”和具体审核问题；清理前端任务标记后刷新运行状态。
- 明确点击修订才授权一次定点修订，保留原稿及审核报告；禁止改动未点名场次，不把修订后通过计作首稿通过。
- 商品策略字段在新写作、旧稿审核推断、修订中使用一致约束。保留 Agent 不限运行时长的设置。

验证：81 项回归测试通过；真实渲染函数使用现有项目失败状态进行隔离页面验证，旧版/新版待修订、运行态、键盘操作、200% 放大均通过，最终检查无 axe 违规或横向溢出。未调用本次用户剧本的付费修订，也未宣称剧本已审核通过。
