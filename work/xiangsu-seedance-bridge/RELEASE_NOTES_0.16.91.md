# 纯梦短剧老虎机 0.16.91（本地交付）

本版本已静默安装到当前电脑，并生成独立 Windows 安装包。官网、公共下载清单和自动更新源保持不变。

## 修复

- Gemini 收到带恢复时间的临时配额响应时，在同一逻辑会话中按上游窗口有界等待；累计恢复预算为 20 分钟，不再被旧的固定尝试次数提前截断。
- Gemini 每日或项目配额确实不可用时，保留已完成剧本与结构化断点，不无限循环、不重复消费请求额度；额度恢复或切换可用模型后继续。
- 文本供应商、参考素材上传和远端视频下载统一使用 Electron 网络栈，跟随桌面应用的系统代理、证书和 DNS 行为，消除 Node/Undici 与 Electron 分裂导致的 `fetch failed`。
- 仅明确的 429/5xx 或可证明尚未连接上游的错误允许有界恢复。付费 POST 在派发状态不明、已收到响应头、已有部分内容或回执时只保存断点，绝不盲目整单重放。
- 参考图、参考视频和参考音频上传增加 20 分钟生产看门狗、全局三路并发、内容哈希去重、进行中 Promise 合并与成功 URL 缓存。五个分镜同时引用同一素材时只上传一次。
- 远端视频已经生成但本地下载中断时，只继续查询或下载原 `taskId`；签名 URL 的临时查询参数不再改变任务指纹，避免重复创建付费视频任务。
- 媒体探测、图片兼容转换、参考上传、成片下载以及无 `taskId` 的提交恢复均采用至少 20 分钟生产窗口；用户主动暂停或取消仍立即生效。
- 结构化 JSON 中断后允许从字符串、逗号或空白中间续补，不要求上游重写完整结果；已有内容与回执存在时不会重放整次请求。
- 主工作台、简易模式、任务队列和历史状态统一把网络、限流、配额与上游异常转成可操作的中文恢复提示，不再显示原始 `fetch failed`、URL、请求 ID、模型 ID 或凭据片段。
- 简易模式包内审计同步适配真实首开新手引导：等待引导展示、正常点击“我知道了”并保存已读状态，再继续页面检查。

## 安全边界

- 尚无远端 `taskId`：只恢复参考素材准备，并复用原幂等请求标识。
- 已有远端 `taskId`：只查询或下载原任务，不重新提交生成。
- 模糊 POST 结果：不自动重放，保留断点等待明确恢复操作。
- 本次构建、离屏审计和安装审计没有提交真实图片或视频任务，`paidJobCount=0`。
