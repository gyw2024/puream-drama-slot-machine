# 纯梦短剧老虎机 0.16.121

## 大项目性能优化

- 启动项目列表只读取轻量索引和 Foundry 状态头，不再解析全部 SQLite 项目快照及 JSON 镜像。
- 已完成的 Foundry 和资产元数据迁移不再每次启动全库重跑；单项目读取仍会执行必要的兼容修复。
- 40 个内置音色按音色包版本和审计指纹复用，文件未变化时不再重复哈希、声学审计和写库。
- 大项目基线只做一次隔离克隆；页面切换直接渲染当前内存状态，不再重复跨进程读取整份项目。
- 音色、人物、候选和全局资产库改为分批显示，避免一次创建数百个媒体卡片。

## 验收范围

- 在真实 91 项目、36 MB 项目镜像、993 项全局资产、94 个音色的数据规模上复测启动、页面切换、空闲占用和 DOM 规模。
- 完成全量源码回归、打包态、安装态和重启态检查。
- 使用《董事长的最后一支舞 / 九宝茶》真实项目继续完成资产复用、缺失生成、分镜视频和最终成片全链路。
