# 纯梦短剧老虎机 0.16.127

本版本新增“Codex 成片资产包”直达生产模式，并把图生视频提示词统一到海螺官方六段式英文导演模板。

- 新增单文件 `.pdramapack` 导入：自动校验清单、资产哈希、分镜、角色绑定、说话人和对白，导入后直接进入逐镜视频抽卡。
- 默认启用“仅参考图、不传音频”，所有模式统一使用纯英文控制指令，只有 `<d>` 标签内保留原始中文台词。
- 严格锁定说话人、完整台词、情绪表演、站位朝向、镜头运动、单一人物身份和无字幕/无杂音/无多人抢话规则。
- 每个分镜的远端视频任务使用持久化幂等键和一次提交门禁；失败不会自动创建第二个付费任务。
- 资产识别只保留有直接镜头的主要人物和推动剧情的核心物品，并复用已确认资产库；新增 40 种按性别和年龄段验证的内置音色。
- 新增配套 Codex Skill，可把剧本、逐镜中英提示词和全部资产打成应用可直接识别的单文件生产包。
- 修复旧中文动作摘要污染英文供应商提示词、虚构第三句对白、商品口播人物朝向错误，以及图片模式错误预留音色的问题。
- 发布门禁覆盖 758 项自动化回归、真实包导入、1280×720/1440×900/200% 界面、键盘操作、无障碍与运行时错误检查。

根因范围：提示词编译边界、对白不可变账本、资产包导入校验、视频任务幂等门禁、资产资格判断和音色元数据。
