# 纯梦短剧老虎机 0.16.103

- 自主上传剧本在 AI 无损标准化完成后，改由本地确定性编译器一次性生成场景、人物、核心道具、对白归属和分镜，不再发起重复的长文本分析请求。
- 已有 `Sxx` 镜号的台词只按镜号归属；仅在没有镜号时才使用原文偏移，杜绝后续镜头的情绪、说话人或口型元数据污染前一镜。
- 对白时长采用柔性调度：按完整台词自然语速延长或拆成连续制作单元，不因参考总时长截断对白，也不会以结构审核中断流程。
- 分镜首帧、尾帧和逐秒合图提示词全部写入明确的 `9:16` 画幅合同，并继续禁止字幕、可读文字、黑边、拉伸和挤压。
- 静态分镜提示词不再采用“最后一个硬合同覆盖前文”的裁剪方式；画幅、人物、说话人/嘴型、商品硬绑定、首尾状态和输出形态等每个 `【…】` 结构块都会保留，长说明只压缩非结构化铺垫，避免商品或对白归属在提交前静默丢失。
- 道具按语义名称和状态别名合并；“破损的礼服/修复后的礼服”只保留一个资产。新一轮道具编号变化不会再串到旧资产，未命中的道具也不会错误扩散到全剧所有镜头。
- 柔性拆镜后会清理无对白子镜残留的说话人和嘴型所有权，避免 A 的台词被 B 的口型承接。
- 长文本官网中转已配套支持流式转发，客户端能持续收到首字节和进度，不再因代理整包缓冲制造假超时。

本版本仅更新本机与安装包，未发布官网安装包。
