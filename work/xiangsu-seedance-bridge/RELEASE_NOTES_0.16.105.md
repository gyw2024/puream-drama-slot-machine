# 纯梦短剧老虎机 0.16.105

- 新增“资产直投 H3”制作模式：不生成分镜图，人物、场景、物品/商品和人物音色资产确认后，直接作为 H3 多模态参考进入分镜视频。
- 所有视频供应链统一为纯梦官网 H3；移除像塑、Seedance 以及旧插件运行文件和入口，旧项目设置仅作无损迁移输入。
- 对话镜头由 AI 编排完整台词、说话人、监听者、情绪、表情、语气、动作和切镜；优先使用 10–15 秒完整镜头，单句不拆断，一个 15 秒内镜头只创建一个付费 H3 任务。
- 资产直投模式的提示词确认弹窗不包含分镜图和人物视频，后续只展示实际会调用的人物、音色、场景、物品/商品和分镜视频提示词。
- H3 已提交任务恢复下沉到主进程，不再依赖用户是否进入某个页面；活动任务自动查询、下载并回写，界面关闭或初始化暂时失败也不会丢失恢复链路。
- 兼容旧版 `%LOCALAPPDATA%\SeedanceBridge\remote-tasks.json`，并可从项目 taskId 自动重建下载目录映射，解决上游已完成但客户端长期停在“恢复已提交任务”的问题。
- 真实付费测试增加独立文本/图片/视频预算上限、阶段状态和断点幂等；已付费结果未知时绝不自动创建第二个任务。
- 修复资产直投首个人物/场景被自身“前序资产”门禁阻塞、同一 H3 任务完成后被本地拼接记录误计为第二次提交、说话人切换数取错结构层、单镜头后半段关键动作被截短等根因。
- 用户界面统一显示“纯梦云端视频”，不再把底层视频型号写进产品文案；模型标识仍仅保留在内部协议和恢复索引中。
- 客户项目、授权和资产库继续使用既有持久目录；安装与升级不清空、不搬移、不重写用户数据。

本版本先更新本机与独立安装包，不发布官网安装包。
