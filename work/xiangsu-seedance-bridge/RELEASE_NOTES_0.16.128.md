# 纯梦短剧老虎机 0.16.128

本版本修复 Codex 资产包被误标为“资产直投/首帧”的根因，并新增真正独立的“Codex 资产包直抽”模式。

- `.pdramapack` 导入后固定进入 `production_package`，不会再冒充普通资产直投。
- 包内 `shot_anchor` 保持镜头级合成参考语义；它不是首帧、尾帧、关键帧或资产直投身份图。
- 旧版已导入项目自动迁移到正确模式与候选血缘，普通资产直投项目不受影响。
- 导入剧本、资产、逐镜中英提示词和图片顺序只读锁定；不再生成或改写资产、分镜图和提示词。
- 视频提交只使用包内精确英文控制稿与原顺序图片；中文只存在于对白标签，不参考音频，不延续上一镜视频。
- 每个分镜最多创建一次上游视频任务；全项目预检失败时保持零提交。
- Codex Skill 同步改为 package-owned shot reference 契约，禁止再把镜头锚点描述成 opening/first frame。
- 全量自动化回归 `771/771` 通过；安装态真实包导入和多缩放 UI 审计随本版本交付。

根因范围：资产包导入模式建模、候选资产血缘、工作流只读边界、视频幂等门与 UI 模式表达。
