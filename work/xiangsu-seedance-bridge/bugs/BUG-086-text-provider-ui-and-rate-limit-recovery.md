# BUG-086 文本供应商 UI 与限流自动续接

## 用户现象

- 文本模型供应商下拉框中出现多个笼统的“文本模型”，无法判断实际厂商。
- 纯梦官网内置 GPT 与 Claude 未明确展示。
- Gemini 测试连接会占用一次生成请求；触发 429 后任务可能直接显示原始上游报错。

## 根因

1. 全局模型名脱敏扫描错误覆盖了设置页的 `select/option`，把本应由用户选择的厂商和模型名替换为通用词。
2. Gemini 连接测试复用了文本生成接口，而不是只读取模型目录。
3. OpenAI 兼容流式适配器在非 2xx 分支重建了普通错误，丢失 `Retry-After`、Google `RetryInfo` 和配额窗口；通用文本入口也缺少统一的限流恢复层。

## 修复

- 设置卡及其选项不参与运行结果脱敏；所有供应商显示明确厂商，纯梦官网明确显示内置 GPT / Claude。
- Gemini 连接测试只调用 `models.list`，不调用 `generateContent`，不消耗生成配额。
- 保留并解析上游限流元数据；对瞬时 429 在同一会话、同一幂等键下按恢复窗口自动续接，生产等待预算不少于 20 分钟。
- 日配额只允许一次具有明确恢复时间的边界探测，随后保存断点并结束自动调用，避免无限循环和持续扣费。
- 已收到部分输出、完成回执或收费回执后绝不整请求重放。
- UI 显示预计等待秒数和“同一请求续接”，不再直接展示原始厂商错误。

## 回归要求

- 完整测试套件通过。
- 供应商 UI 在 1280×800、1440×900、1920×1080 和 200% 缩放下无溢出、遮挡或严重无障碍问题。
- 瞬时 RPM 恢复、RPD 有界停止、部分输出不重放、Gemini 无生成配额连接测试均有自动化覆盖。
- 安装前后用户配置、历史项目及资产库只读清单一致。
