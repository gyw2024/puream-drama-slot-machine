# BUG-094：资产直投可能自阻塞、误计重复视频任务或削弱对白与动作所有权

## 现象

- 资产直投模式的首个人物或首个场景可能一直停在等待前序锚点，无法进入真实资产生成。
- 一个上游视频任务完成并在本地拼接后，验收统计可能把本地 `agent-stitch-*` 成品记录误计为第二个付费任务。
- 多人对白的切镜预算显示为 0，或单镜头后半段决定性动作没有完整进入最终视频提示词。
- 产品界面仍显示底层视频型号，安装态审计因此与产品化显示边界不一致。

## 深层根因

1. 首锚点和后续锚点复用了同一前序依赖判断，没有显式表达“序列第一项没有前驱”。
2. 任务统计把“上游提交身份”和“本地派生成品身份”混在同一候选集合中，没有以 provider taskId/request key 为唯一付费边界。
3. 说话人切换数读取了 provider block 数，而不是按对白账本计算相邻 speakerId 变化；单子镜头又优先使用较短的子镜头动作摘要，并在兜底方向中按 105 字符截断。
4. 显示层把内部 provider 名称当成产品名，且 UI 审计曾把本地证据路径中的普通 `H3` 片段误认成界面泄漏。
5. `node --test` 未显式提供沙盒目录时，文本供应商遥测路径错误回落到客户真实 APPDATA，导致回归测试污染真实诊断日志。
6. 简易模式首次引导依赖 `requestAnimationFrame`，后台或离屏启动时帧回调可能被 Chromium 暂停，页面已就绪但新手引导不弹。

## 根修复

- 首人物/场景允许无前驱进入，后续项目仍严格等待已确认的连续性锚点；重抽保持当前选中锚点。
- 付费计数只认稳定 request key 与真实 provider taskId，过滤 `agent-stitch-*` 等本地派生记录；累计提交次数随阶段状态持久化，恢复运行只查询原任务。
- 按相邻对白说话人计算切换数；单子镜头优先保留父镜头完整 `actionEn`，动作方向容量提高到 220 字符，仍不截断完整对白。
- 所有用户可见视频品牌统一为“纯梦云端视频”；内部 provider ID、任务恢复键和模型协议保持不变。审计仅排除明确的本地路径字段，不放宽其他可见文案检查。
- Electron 生产入口继续显式传入用户数据目录；Node 测试 worker 未提供明确沙盒时禁写供应商遥测，防止测试进程落入客户 APPDATA。
- 简易模式首次引导改为微任务调度，不再依赖窗口可见或下一次绘制帧。

## 验证

- 全量自动化回归：651/651 通过；其中包含测试遥测零生产写入专项。
- 3 分钟资产直投提示词链：15 镜、180 秒、27/27 提示词确认、0 分镜图、0 人物视频、0 提前媒体调用。
- 真实付费测试只创建 1 个上游任务 `cmtblovai00nav653v20tgn9n`，恢复复跑提交次数为 0；文本 ¥4.86、图片 ¥0.30、视频 ¥1.22，总计 ¥6.38。
- 打包态 Agent、简易模式、新手引导、100%–200% 缩放和严重无障碍审计通过；安装前后用户数据逐文件哈希比对为零差异。
- 完整回归前后 1,526 个客户文件再次逐字节比对，`added=0 / removed=0 / changed=0`。
