# BUG-088：商品上下文误拦截与语义编译失真

## 现象

- 用户已经选好题并仍有文本余额，修改或重新保存商品资料后，写作阶段显示“商品资料在选题生成后发生了变化，请重新生成一轮适配当前商品的选题”，项目无法继续。
- 上游返回完整内容后，本地制作稿仍可能出现“行动推进6”、状态句停在“接受并坐到”等占位或半句。
- 一句台词的说话人正确，但系统把听者猜成同镜另一个人物，导致正反打、视线和口型对象错误。
- 审核蓝图关闭后，项目数据与界面仍显示语义终审100分，掩盖了“未审核”事实。

## 最深层根因

1. 选题与商品使用了包含图片绝对路径、空格和分隔符的原始快照做全等比较；保存顺序、路径迁移或无语义格式变化都被误判为商品已换，且旧失败状态会持久化。
2. 剧本签名的多个消费者各自做原始字符串比较，旧断点可能被错误作废，已经完成的剧本也可能被再次计费重写。
3. 语义编译器对叙事字段直接执行 `slice()`，把上游完整句子截成半句后继续传给剧本、分镜图和视频提示词。
4. 对白语义协议只锁定说话人、台词和语气，没有锁定听者；本地编译只能从可见人物中猜测，三人关系镜容易绑错对象。
5. 快速写作通道把“通过确定性格式合同”等同于“所有语义维度100分”，审核关闭时仍生成虚假评分。

## 修复

- 商品上下文升级为语义规范化比较：名称、卖点、模式决定是否真正变化，图片路径和无意义格式不再触发终止。
- 真正换商品时保留已经付费的选题，自动把当前唯一商品名与卖点重新绑定到所选故事并继续写作；旧商品信息只进入审计历史，不进入活动提示词。
- 旧签名、旧断点和旧红色失败状态在读取时迁移为可继续状态；完整脚本不会因路径或格式变化被重复生成。
- 新增完整叙事字段编译：正常上游字段不再按固定字符数截断；异常超长字段只在完整句末裁剪。
- 最后一镜显式锁定 `settlementAction` 与 `emotionalPayoff`；占位动作、悬空状态和重新开启冲突的孤立末句在本地无付费自愈，不触发蓝图重试。
- 对白协议升级为 `[说话人, 完整台词, 专属语气, 明确听者]`，并把听者编号一直传到 `dialogueTurns.listenerIds`、反应和机位；旧三字段结果可从人物姓名或唯一关系安全迁移。
- 审核关闭时标记为“未评分、继续生产”，不再伪造100分；界面同步显示不评分、不拦截。

- 直接写作与语义编译专项：26/26。
- 完整仓库回归：625/625，失败、取消、跳过均为0；覆盖96种模式/输入组合以及文本恢复、二十分钟等待窗、任务幂等、提示词确认、分镜比例、无字幕、授权与并发合同。
- 真实已保存 PUREAM 文本模型隔离运行：旧保温杯选题自动迁移到护眼台灯，完成剧本、3人物、3场景、6分镜、27条资产/合图/视频提示词；未提交图片或视频付费任务。
- 真实结果反向审查发现的错听者、占位结尾和半句截断均已固化为冻结回归样本；修复后的本地编译结果通过，不为同一上游内容再次付费。
