# BUG-087：生成前缺少完整提示词确认节点

## 根因

剧本与商品处理完成后，原流程直接进入资产、分镜合图或分镜视频生成。提示词虽然存在于项目数据中，但没有统一、持久化且覆盖全部入口的人工确认协议，导致用户无法在付费生成前完整查看和修订最终提示词。

## 修复

- 引入 `prompt-review-v2` 项目级确认协议，在剧本与商品处理完成后、任何付费媒体调用前统一暂停。
- 一次性编译并完整列出资产提示词、分镜合图提示词和分镜视频提示词；支持分类筛选、全文搜索和全文编辑。
- 每条提示词支持“保存并确认本条”，也支持“一键保存并确认全部”。空提示词留在弹窗中提示补全，不提交上游。
- 编辑结果写回真实下游字段；确认后的图像提示词原样进入生成，不再被二次拼接或覆盖。
- Agent、简易模式、单项生成、批量生成和一键全流程统一执行同一前置确认；关闭弹窗只保持待确认，不产生系统错误或付费请求。
- 确认后按原入口和原阶段继续，项目或生产修订变化时自动失效旧确认，避免跨项目、跨版本串用。

## 验证

- 完整自动化回归：597/597。
- 专项交互：单条编辑确认、空提示词提示、分类筛选、Escape 暂关、重开、一键确认全部均通过。
- Agent 与简易模式在 1024×720、1280×800、1440×900、1920×1080、200% 缩放下无横向溢出，完整提示词可见，严重/致命无障碍问题为 0。
- 打包态与安装态审计通过；安装前后 1093 个用户文件、2 套 SQLite 新增/删除/修改均为 0。
