# BUG-107：中文多模态时间轴未成为唯一执行合同

## 用户可见现象

- 用户要求的 `integrated_multimodal_description（多模态综合描述）` 只出现在示例或中文摘要中，提示词弹窗与真正 H3 提交文本仍可能保持旧格式。
- 无显式时间码的多段分镜中，人物回应可能被排进群众鼓掌或物品反应镜，造成画面、说话人和嘴型归属冲突。

## 最深层根因

1. 提示词存在展示稿、翻译稿、导演稿、缓存稿和提交稿多份事实源，格式升级只覆盖其中一层。
2. 导演计划已经产出的中文动作、运镜、站位、状态和声音字段在生成块重绑时被丢弃，最终只能回落旧英文镜像或通用句式。
3. 英文朝向字段经过通用关键词翻译后被误写成眼神/表情描述，人物面向听者或镜头的硬语义消失。
4. 对白调度按总剩余秒数移动视觉边界，没有先读取原稿分镜中的说话人证据。
5. 人物基础图与专用换装图、普通对话与 `directToViewer` 收口在中文最终序列化层缺少优先级。
6. 提交前表演合同校验仍按旧格式用“第一个中文右引号”判断语气字段；当语气中再引用“重读词”时，新提示词虽然完整，校验器仍会误报并阻断提交。

## 修复

- `buildApprovedHailuoPrompt` 直接生成唯一中文毫秒时间轴；提示词确认与提交复用该原文。
- 中文导演字段贯穿计划、生成块、缓存重编译和最终提交，不再经过有损摘要。
- 每句对白固定说话人、音色、唯一嘴型、听者闭口、面向目标、语气声调、表情与必要动作；无对白时段显式闭口。
- 无显式时码时，优先用 sourceDialogueId、speakerId、原句和“某人物回应/回答/说出”的分镜语义匹配，再在对应镜头内分配自然语速。
- 专用外观参考压过人物基础图；直视观众收口压过普通听者朝向。
- 表演合同校验改为匹配本行最外层语气引号，并加入内嵌“重读词”回归；不再把合法中文导演稿误判为缺字段。
