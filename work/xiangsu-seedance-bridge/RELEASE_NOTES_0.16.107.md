# 纯梦短剧老虎机 0.16.107

本版本是 H3 资产直投、首尾帧与分镜合图三种主制作模式的稳定性和表演质量补丁。

- 每句对白统一编译说话人、专属音色、声调/音量/语速弧线、表情变化、肢体动作、听者闭口反应、人物站位、朝向、视线与 180 度轴线。
- 群像动作会生成有因果动机的独立反应镜头，不再只让主角在画面里完成所有表演。
- 对白重排和画面切镜使用同一条权威时间线，旧切镜不会让一句话重新开始、重复或转移给听者。
- H3 执行稿维持纯摄影画面合同，不烧入对白字幕、标题、说明文字或界面元素。
- 商品参考图只在包装、瓶/盒/小袋或明确拿取、展示、拆封、挤出动作真实入镜时上传；口播提名、已涂泡沫和染后结果不再浪费参考位。
- 本地资产同时残留历史云端地址时，本地文件成为唯一权威来源；每次 H3 任务都会获得当前有效的任务级临时地址，不再复用已过 24 小时的历史地址让实例空等到一小时超时。
- 自由格式上传稿先经过 AI 标准化，再按来源对白、场景和剧情资产账本解析；同一标准稿可复用于三种模式。
- AI 选题和上传剧本两条入口都可无卡点到达完整提示词确认；提示词确认保留中英文执行稿与本地可编辑中文稿。
- 最终拼接按每镜编剧时长精确对齐画面和音轨，保持竖屏 9:16，并保留已落地 H3 任务的唯一任务号与断点恢复。

发布门禁：源码全量测试、三模式真实文本链、五分钟 H3 成片逐镜 ASR/OCR/画面复审、打包态 UI 与本机升级安装全部通过后，才标记正式可用。
