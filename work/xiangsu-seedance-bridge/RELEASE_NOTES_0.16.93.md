# 纯梦短剧老虎机 0.16.93

## 提示词确认流程升级

- 剧本与商品处理完成后，先生成并弹出完整提示词清单，再进入任何资产、分镜合图或分镜视频生成。
- 清单完整展示资产提示词、分镜合图提示词和分镜视频提示词，不省略、不截断。
- 每条提示词都可直接二次编辑，并支持“保存并确认本条”。
- 支持“一键保存并确认全部”，会同时保存弹窗内尚未逐条确认的修改。
- 一键全流程会在确认前安全暂停，确认后从原阶段继续；直接生成按钮也复用同一确认协议。
- 提示词确认是人工工作节点，不再显示为系统报错，也不会在确认前调用付费媒体生成接口。

## 交互与兼容性

- Agent 模式和简易模式使用同一提示词清单协议。
- 支持按资产、分镜合图、分镜视频筛选及全文搜索。
- 支持关闭后稍后继续、键盘焦点、Escape 暂时关闭、长文本自动完整展开和高缩放布局。
