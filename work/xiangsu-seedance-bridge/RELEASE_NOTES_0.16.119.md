# 纯梦短剧老虎机 0.16.119

## 人物资产、核心道具与音色库修复

- 人物外貌提示词与对白账本彻底分离：人物卡只保留年龄、发型、五官、体型、服装等可见特征，不再把“顾主席，主席通道已经打开”等台词当外貌。
- 保留全部说话人用于对白完整性校验，但只有主角、明确主镜头、至少两个独立正面说话镜头或四个以上持续出镜镜头的人物才建立独立资产。单句围观者、普通反应听者、背景板和画外人员不再抽人物图或专属音色。
- 物品资产改为核心连续性准入：商品本体与组件、杯子、包装、同义重复物品和一次性普通文件不再重复建资产。
- 人物图、核心道具和已确认音色自动进入全局资产库，保存性别、年龄段、主角/配角/特约/龙套/背景/画外、来源、标签和使用次数。
- 升级时会把历史项目中已经确认的合格人物/道具补入全局库；背景、画外和临时龙套的旧文件不删除，但不再出现在可选资产库中。
- 音色库增加真实 WAV 声学核验，修正历史男女声错标；未经核验或性别年龄冲突的音色不参加自动匹配。
- 内置 40 个文件各不相同、可直接试听的 WAV 音色，覆盖男声、女声及青年、中年、老年，并以系统资产保护。

## 真实项目验收目标

- 《董事长的最后一支舞》19 个人物中保留 8 个独立人物资产，11 个单句龙套、背景或画外人物折叠说明。
- 13 个物品台账收敛为婚戒、发黄的旧舞会卡、审计文件、离婚协议 4 个核心道具；九宝茶继续使用独立商品原图。
- 历史“王老师”音色按声学画像修正为男声，“苏晚晴”修正为中年女声。
