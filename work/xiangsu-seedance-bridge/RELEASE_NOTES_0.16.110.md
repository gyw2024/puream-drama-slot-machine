# 纯梦短剧老虎机 0.16.110

## 本地候选补丁

- H3 最终提示词改为完整的“前因 → 动作 → 表演 → 反应 → 结果”导演载荷，不再把上游已经写好的声调、呼吸、重音、表情、身体动作、站位与朝向压成一句笼统语气。
- 同一动作段内的两句对白只执行一次物理动作；换人时只切换机位、说话嘴型与反应，不重复动作、不重置状态。
- 人物、场景、商品和道具使用稳定的 Subject/Scene/Product/Prop/Picture/Audio 映射；同一命名实体在每帧只允许一个物理实例，背景群众不得复用主角脸。
- 场景四视图只作为同一个物理空间的完整几何、光线与轴线参考，不拆成多个房间；发型、服装和道具的剧情变化按当前状态向后延续。
- 道具识别覆盖稳定 ID、中文简称、英文动作/状态和 provider 时间线；补齐剪刀、摔物、门铃、撕纸、开关门、手机震动和掌声等动作声效。
- 有明确剧情任务的第三名角色保留身份参考；仅在场但不入镜的人物仍不会占用 H3 图片槽位。
