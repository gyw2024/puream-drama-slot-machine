## 交付内容

- 完整模式：智能粗剪页新增“一键生成剪映草稿”。
- 简易模式：新增“粗剪与剪映”页面，共用同一后端与状态控制器。

- 草稿包含逐镜视频剪辑、独立剧情音效轨、环境音轨、可编辑字幕轨及独立 SRT。
- 150 个本地固定音效按已有剧情/环境匹配计划放入草稿，可在剪映内各自调整。不是新增付费音效生成。
- 项目目录 `exports/jianying` 始终保存完整草稿；自动检测本机剪映目录，并以新版本文件夹发布，不覆盖用户已编辑的草稿。
- 具有资源 SHA-256 校验、原子目录发布、重复请求去重、取消、重试和失败后保留项目副本。
- 应用自身 MCP 新增 `export_jianying_draft` 与 `cancel_post_production`；本轮没有把新的 MCP 服务写入 Codex 配置。

## 字幕的真实能力边界

完整对白账本是文本来源，支持旧版 `dialogue[]` 与当前 `dialogueTurns`。可信、与当前抽卡版本和对白文本匹配的语音时间戳优先；缺少时使用计划/估算排时，并在界面、草稿说明和清单中明确标注。

本轮没有调用在线 ASR，也没有宣称估算字幕已经逐字听写或口型校验。字幕生成是自动的，首次打开剪映仍需预览校时。不会为了填满字幕而编造或重复台词。

## 发现并修复的根因

| 根因 | 修复 |
| --- | --- |
| 旧式结构化对白被当成字符串，字幕为零、界面出现 `[object Object]` | 统一对白读取与展示适配器；未编辑时保留原结构 |
| 粗剪仍叠加固定音效，无法在剪映单独调整 | 粗剪与音效计划分离，音效仅写草稿音轨 |
| 无音轨视频按脚本时长截短、输出画幅固定竖屏 | 探测真实视频时长，保留实际内容和画幅，缺音轨补静音 |
| 取消没有传到元数据清理、质检子进程和排队等待 | 按项目隔离的取消上下文贯通 FFmpeg/ffprobe、扫描与队列 |
| 元数据探测重复解码整片、同步读取整个视频 | 仅读元信息；文件扫描改异步分块 |
| 长片重复画面比较连续占用主线程 | 每批让出事件循环并检查取消；保留原算法和阈值 |
| 异常退出后的本地 `running` 状态残留 | 恢复/取消时将孤儿本地任务归一为可重试中断，不修改上游任务 |
| 本地超时显示成上游恢复，迟到取消可能显示完成 | 按本地错误码和取消状态准确显示，不假报成功 |
| 局部质量提醒强制撤销已选视频并要求重抽 | 可编辑粗剪保留源片并给出提示；真正缺文件、损坏解码仍明确报错 |
| 模板残留“最多两名可见人物”，代码 `slice(0, 2)` 丢第三人 | 保留全部真实可见人物；说话人上限与可见人物分开处理 |
| 校验器按最近提到的人物猜说话人 | 按明确发声动词和对白语义绑定，保留真实错绑的否定回归 |
| 紧凑模板优先读中文动作，丢弃已编译英文表演；语气和开口时间未共用主分支规则 | 优先采用已编译英文动作/镜头，沿用语气推导与正常语速时间核算 |
| 圆括号转场说明被当成角色对白 | 元数据标签归一化，保留真人物的括号语气和画外音 |
| 窄窗口顶栏三行挤进两行固定高度 | 响应式双行布局，主内容保持可滚动操作 |

## 使用路径

完成分镜视频后，进入“智能粗剪”，先生成无叠加音效粗剪，再点“一键生成剪映草稿”。也可直接从已有分镜导出；此时会明确提示未继承片头裁剪。简易模式从“04 粗剪与剪映”进入。

手动启动剪映，刷新草稿页并打开新草稿。视频、环境音、剧情音效、字幕可以分别修改；若本机剪映没有自动发现目录，保留项目副本并在导出面板指定实际草稿根目录后重试。不要删除用户已有草稿或改写剪映自管索引来强行通过验收。
