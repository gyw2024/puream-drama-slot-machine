# 短剧固定音效试听清单（候选版）

用途：从固定内置音效库按明确剧情事件匹配，不生成新音效，不让模型自由发挥。

试听原则：每类最终保留 2–4 个不同力度版本；所有音效必须无语音、无水印、无字幕信息、无旋律尾巴。正式入库前统一转为 48 kHz、24-bit WAV，并记录来源、许可证、SHA-256、响度、峰值和时长。

## 固定匹配规则

1. 只有画面中确实发生了动作，或动作在画外有明确剧情依据时才能加对应音效。
2. 一镜默认 0–2 个音效；高潮镜最多 3 个，不允许铺满。
3. 对白开始前后 150 毫秒禁止放置非动作必需的撞击、点击、咂嘴类瞬态声。
4. 耳光、拳击、关门、跪地、物品落地必须逐帧对准接触点，不能提前或延后。
5. 不得使用带人声、喘息、咂嘴、喊叫或可辨识台词的素材，避免重新引入杂音和抢话。
6. 人群声只允许不可辨认的低声氛围，台词优先级永远最高。
7. 同一音效不得在相邻三个镜头重复使用同一个文件；应从同类 2–4 个变体中轮换。
8. 音效匹配失败时跳过，不能阻断粗剪输出，也不能用错误音效凑数。

## 试听素材候选来源

- [CC0 Public Domain Sounds 合集](https://github.com/lavenderdotpet/CC0-Public-Domain-Sounds)：包含门、脚步、撞击、纸张、玻璃、木材、金属、雨声、衣料和 Kenney 系列音效。
- [sound-cc0](https://github.com/code4fukui/sound-cc0)：体量较小，适合铃声、开关、金属落点等补充试听。
- [Freesound CC0 Designed Impacts](https://freesound.org/people/doudar41/packs/40663/)：用于呼啸、重击、反转落点的候选试听；正式入库仍需逐文件复核许可证。

## 最终入库建议

- 首版内置 72 个“用途槽位”，每个槽位从试听候选中选 1 个主版本；高频类别（脚步、门、耳光、呼啸、重击、纸张、产品操作）额外保留 2–4 个变体。
- 预计最终文件数 110–140 个，但对软件暴露的仍是上述 72 个语义槽位，匹配逻辑保持简单、可解释、可人工替换。
- 不内置枪声、爆炸、怪物、魔法、游戏金币、语音喊叫等与现实短剧高频需求无关或容易破坏写实感的素材。
