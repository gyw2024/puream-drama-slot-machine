# 纯梦短剧老虎机：新版设置与使用教程

适用版本：0.16.339 源码候选版（尚未安装或官网发布）。更新日期：2026-09-15。

本教程按软件实际入口编写。先完成“首次设置”，再按所选工作模式操作。模型清单、账号额度和价格以当前客户端及服务商显示为准。

## 本版新增：时长、并行提示词与运行日志

- 完整内容与质量意见分开处理：AI负责原稿忠实度、表演、因果和带货方式的判断；时长估算、字数或动作推断不会单独触发程序退稿。完整稿件可在审核窗口查看。明确缺陷由 Agent 定位并修订；证据不足单独显示“待补证据”，不冒充通过。修改后先复核受影响内容，再由用户确认；提交生成时使用的就是当前展示并确认的版本。
- 场景原始描述完整保留，由Agent提取无人场景。导演同时读取已确定的场景光照、时段和布局。资产设计绑定当前原稿；原稿变化时由Agent复核旧设计，避免沿用错误年龄、身份或场景。
- Agent返回格式异常时，保留原返回和成功条目，自动进入格式恢复或独立诊断；完全相同的无效结果不会反复付费重发。诊断后仍缺证据时保留断点和具体原因。主动取消不会自动重发，界面只有在实际安排自动续接时才显示“后台自动继续”。

- 分镜编排前，Agent 会先统一规划全片的物件持有人、放置位置和跨镜状态，以及动作与具体对白的先后关系。界面会显示“全片连续性规划”；该阶段不需要额外点击确认，也不会生成图片。完成后再按每批最多 5 镜并行编排。
- 画外字幕与剧情内书写分开处理：禁止额外叠加的文字和图形，保留原稿要求的签名、牌面及包装原有文字。首尾帧“闭口”仅指嘴唇，不代表闭眼。
- 期望时长与允许范围分开处理。导演在已保存的范围内安排完整剧情，不会仅因合计没有精确等于期望秒数而拦截。
- 角色身份、场景空间和镜头中的临时状态分别管理。商品包装原图继续作为外部参考；持物、开包装、交接及人物视线按实际时刻进入分镜和首尾帧。
- Agent 的最终有效结果与过程警告分别识别；明确取消、返回不完整或真实审核失败仍会显示原因并保留已完成部分。不能把入口连通、单次通过或程序测试通过理解为所有内容必然合格。

- 完全新创剧本：首次写稿随机选择 8–10 分钟目标并保存，同项目继续运行不会重新抽取。允许略短或略长，由 Agent 结合剧情、对白完整性和实际可演性审核，不因旧项目的固定秒数范围反复退稿。
- 上传剧本改写：保留原稿时长基准，改写后分镜总时长与原稿相比最多相差 30 秒。原稿有时码时优先使用时码；没有时码时由 Agent 根据完整原稿可演性估时并缓存该依据，标注为估算，不把估时称作视频实测时长。
- 分镜提示词：支持每批最多 5 镜、最多 4 个子任务并行，共享原稿与相邻分镜状态。AG 当前按其会话能力串行执行。已完成批次逐批保存，继续时复用；同时运行不代表速度固定提升四倍。
- 所有提示词生成后进入“提示词确认”，由用户核对并确认。原稿、台词、数量、因果及参考资产仍会被校验；服务商额度或网络失败会保留断点，不会假报完成。
- 导出排查日志：在 Agent 模式或简易模式先选择需要排查的项目，点击侧栏“导出运行日志”，在保存窗口选择 ZIP 文件位置。任务进行中也可导出；导出时按钮显示“正在导出…”，完成后显示文件数量。取消保存不会影响项目。
- ZIP 包含该项目快照、可用的 Agent 请求与返回、阶段日志、脱敏设置和文件清单，不打包媒体。剧本及提示词属于项目业务内容，仍会保留，发送前请确认接收人。旧版未记录的运行过程不会补造，缺失或容量限制会写入包内清单。
- 同一原稿重复进入拆镜会复用已完成的拆镜、资产设计和导演方案；修改原稿后重新校验。组合道具保留其真实数量，固定墙钩等资产保留安装位置，不再被通用模板强制变成摄影台上的单个物件。

## 1. 第一次使用：从安装到能够生成

1. 从 [纯梦官网软件页面](https://puream.cn/drama-slot-machine) 下载 Windows 安装包。升级前让正在运行的任务结束，保存正在编辑的内容，再退出软件安装；不要删除项目数据目录。
2. 启动软件，遇到激活窗口时填写官网取得的“纯梦授权码”，点击“在线激活”。授权码不是 Codex、AG 或 WorkBuddy 的登录密码。
3. 进入 Agent 模式，左侧打开“系统设置”。先配置写作来源，再配置图片和视频来源。
4. 在“项目与素材保存位置”查看实际目录。需要迁移时用“更改保存位置”：软件复制现有数据、保留旧目录并重启。不要在生成中迁移，也不要只移动某个项目 JSON。
5. 配置完成后点击页面顶部“保存全部设置”。回到设置页，确认所选来源、模型和路径仍被保留。
6. 用一个小项目验证“写作 → 全部提示词待确认”；检查无误后再确认进入图片、视频生成。入口检测通过不等于真实生成通过。

### 需要准备哪些资料

| 资料 | 用途 | 怎么准备 |
| --- | --- | --- |
| 纯梦授权码 | 软件授权和所选官网算力服务 | 在官网取得；按设置页分别填写和验证 |
| 本地 Agent | 代写剧本、拆镜、编写或审核提示词 | 安装所选 Agent，完成其自身登录，确认账号可用 |
| 剧情需求或已有剧本 | 规定故事和对白 | 写清人物、关系、冲突、结局及必须保留的内容 |
| 商品原图 | 带货商品身份和参考素材 | 上传真实商品图片，名称与图中商品一致 |
| 商品资料 | 带货内容依据 | 填真实卖点、价格和活动；没有活动写“无促销” |
| 本地存储空间 | 保存参考资产、视频、成片和任务记录 | 选择空间充足的本地目录，记住实际保存位置 |

## 2. 先分清 Agent 模式与简易模式

| 模式 | 负责什么 | 从哪里进入 |
| --- | --- | --- |
| Agent 模式 | AI 选题、写剧本、拆镜、资产设计、提示词、审核及后续生产 | 完整工作台；简易模式内可“切换到 Agent 模式” |
| 简易模式 | 按您填写的分镜制作资产、合图和视频；不选题、不写剧本、不调用文本模型写作 | 顶部“简易模式”或设置中的“切换到简易模式” |

两种模式的项目、任务、费用、设置和成片分别保存，只共享人物、场景、道具、商品和音色资产库。切换模式后项目列表不同，不表示项目丢失。需要找原任务，请先切回创建任务时的模式。

## 3. 本地 Agent 详细设置

### 3.1 五个阶段要分别选择

在“系统设置 → 本地 AI 工作软件”中设置以下五项：

| 阶段 | 作用 | 应检查的能力 |
| --- | --- | --- |
| ① 选题与剧本编写 | 选题和完整剧本 | 能输出足够长的完整文本 |
| ② 拆剧本分镜、提炼资产、资产与视频提示词 | 形成资产清单和逐镜提示词 | 能理解因果、人物、参考资产和结构要求 |
| ③ 剧本与提示词审核 | 按启用的审核规则检查文本 | 有可用的文本推理能力 |
| ④ 后期特效音匹配 | 后期声音素材匹配 | 后期工作端和所需工具可用 |
| ⑤ 人物、场景、道具与分镜图片 | 生成实际图片 | 必须有真实生图工具，仅能聊天不够 |

更换①不会自动更换其他阶段。若准备统一使用 Codex，逐项选择 Codex；⑤只有在该 Codex 工作端确实可返回图片时才选择它，否则明确选“软件内置 API（保留原设置）”并配置图片授权。

### 3.2 直接调用与 MCP 接管怎么选

**官方非交互 CLI：** 软件调用 Agent 提供的命令入口并读取结果。适合该 Agent 已安装且具备可用非交互入口的情况。填写实际执行文件，不要填桌面快捷方式、安装包或其他 Agent 的文件路径。

**外部 Agent 通过 MCP 接管：** 需要在外部 Agent 中安装本软件提供的 MCP 配置，再让该 Agent 执行接管指令。只打开 Agent 窗口不会自动完成接管。

按以下顺序操作：

1. 选择所需 Agent，展开对应设置卡片。
2. 选择“接入方式”，核对“执行文件路径”。自动发现的路径也要确认对应当前安装版本。
3. 点击“刷新模型列表”，等待结果，并查看模型来源说明或错误提示。
4. 选择模型、思考强度和速度策略。
5. 点击“检查执行入口”；再看上方“检测接入状态”的结果。
6. MCP 模式还必须完成下一节的外部配置和接管步骤。
7. 点击“保存全部设置”，再进行一次小规模真实写作验证。

### 3.3 模型列表、模型 ID、思考强度

“跟随 Agent 自身默认（不指定模型）”表示软件不指定模型，由该 Agent 当前默认设置决定。想固定某个模型，就明确选中它；不要同时以为它会跟随默认变化。

模型未出现时：先在 Agent 自身确认该账号能使用它，再更新 Agent，点击“刷新模型列表”。观察来源说明：原生 CLI 清单、本地缓存和运行时识别不是同一件事。桌面上出现的新模型可能尚未暴露在 CLI 清单中。

“手动输入其他模型 ID”应填写服务端接受的精确 ID，不能只把桌面显示名称猜成 ID。标记“保留当前配置”的条目表示保留旧选择，不代表本次已验证可用。

“思考强度”只选择该模型支持的值；不确定时选“跟随 Agent / 模型默认”。“速度策略”影响请求偏好，不是运行时长上限，也不是加速承诺。

### 3.4 Codex

1. 在 Codex 自身完成登录，并确认能执行普通任务。
2. 软件中选择 Codex，核对其真实命令入口。
3. 刷新模型列表，按需求选择实际存在的模型。需要 Astra 中等时，选择清单中的对应 Astra 模型与 medium / 中等强度，不要把显示名称写成未经验证的 ID。
4. 配好五个阶段并保存。真实验证应看到软件项目中新增剧本或提示词，而不只是“入口可用”。
5. 使用 Codex 生图时，确认工作端拥有生图工具并实际返回图片文件；文本生成成功不代表生图工具已接入。

### 3.5 Antigravity（AG）

1. 在 AG 完成登录并确认模型可用；软件选择 Antigravity 的官方非交互 CLI。
2. 核对 AG CLI 执行文件。某些安装的命令文件名为 agy.exe，具体以实际安装为准。
3. 刷新模型，选择当前返回的精确型号与档位。测试 3.7 Flash 时应选实际存在的对应档位。
4. 保存并测试。运行中看本软件的任务详情和更新时间，不要因 AG 命令行一次等待返回就重复点击生成。

新版没有给 Agent 任务设置总运行时长上限。AG 命令行的单次等待结束后，软件会继续跟踪本任务对应会话的完成结果。明确的登录、权限、额度、网络错误仍需要按错误处理；软件不会把空响应当成完整剧本。需要结束时使用任务取消或停止入口。

### 3.6 WorkBuddy、DeepSeek Harness、Grok Build

通用步骤仍是“登录原软件 → 核对执行入口 → 刷新模型 → 指定阶段 → 保存 → 真实小任务验证”。

WorkBuddy 的桌面模型菜单和命令入口暴露的清单可能不同。不要把桌面可选模型自动等同于软件已同步成功。先刷新，查看返回来源；未列出的模型只有确认命令入口接受精确 ID 后才手动填写。生图采用 MCP 接管时，接管工作端必须具有生图工具。

DeepSeek Harness、Grok Build 也需要其自身运行环境、登录或配置正常。更换 Agent 时同时检查接入方式、执行路径、模型 ID 和阶段分配，避免沿用另一家 Agent 的模型或路径。

### 3.7 MCP 配置：完整步骤

1. 在设置中找到 MCP 配置区，点击“复制通用 MCP 配置”。服务名称为 puream-drama-workbench，连接方式为 stdio，启动参数为 --mcp-stdio。
2. 将复制的完整 JSON 添加到所选 Agent 自身的 MCP 设置中。使用软件生成的当前安装路径，不照抄别人的 D 盘路径。
3. 保存后，让 Agent 重新加载 MCP 配置，确认该服务连接成功、工具可见。
4. 回到本软件，选“外部 Agent 通过 MCP 接管”，点击“复制接管指令”。
5. 将指令发送到已连接 MCP 的 Agent 会话执行，再检查本软件的工作端在线状态。
6. 提交一个小任务，确认结果回到正确的项目和阶段。

stdio 接入不需要您自行编造网址、端口、令牌或 API Key。安装位置改变后重新复制配置。只复制但未添加配置、添加后未重新加载、没有执行接管指令，都会导致工作端未连接。

## 4. 内置文本、图片、视频设置

### 4.1 写剧本与拆镜文本算力

选择“软件内置 API”作为某文本阶段来源时，才由这里对应的文本服务处理该阶段。

| 字段 | 怎么填写 |
| --- | --- |
| 供应商 | 按实际账号选择纯梦官网、OpenAI 官方、OpenAI 兼容厂商、Google 官方或 Anthropic 官方 |
| 请求地址 | 官网模式由软件锁定；其他供应商按其官方接口说明填写，不填聊天网页地址 |
| 授权码 / API Key | 填当前所选供应商对应凭据，不混用不同平台密钥 |
| 模型 | 选账号真实可用的模型或填写正确模型 ID |
| 最大输出 Token | 为完整剧本预留足够输出，同时不超过模型支持范围；太小可能截断 |
| 输入、输出单价 | 外部服务未返回结算金额时用于估算，填写后不代表改变服务商真实价格 |

点击“测试连接”，查看结果后保存。测试连接与长剧本真实生成要分开验证。

### 4.2 角色、场景与分镜生图

使用内置图片 API 时，在该卡片填写“纯梦授权码”，点击“验证授权”。官网地址与模型为锁定项，无需自行修改。生成图片后应能看到实际缩略图、预览结果和可用参考地址。

图片阶段若已选择本地 Agent，该 Agent 的生图工具、账号和实际输出另行验证。选择了 Agent 文本模型，并不自动获得图片服务。

### 4.3 纯梦云端视频算力

1. 填写“纯梦授权码”，点击“校验配置”。视频服务为“纯梦云端视频（唯一）”。
2. 设置“视频输出分辨率”：480 标准或 768 高清。它控制视频，不会把商品原图或人物图自动改成同一分辨率。
3. “调用模式”一般保持“自动识别（推荐）”，由项目制作策略决定输入结构。手动选择文生、首尾帧、参考图或视频续接时，必须满足对应素材要求。
4. 设置“说话声线来源”。“仅参考图 · 不传音频”不会上传音色文件；“参考图 + 可选音色音频”才使用相应音频参考配置。
5. 保存全部设置。正式生成前查看提交范围和费用提示。图片、视频和外部 Agent 的费用分别取决于所用服务及账号。

### 4.4 审核蓝图与系统提示词

“审核蓝图”可控制总开关及剧本、资产、分镜图、视频、交付等模块。开启后按已选规则审核；关闭后不会执行这些审核拦截和自动返修，但读取数据与上游接口必填要求仍然存在。

关闭审核不是“审核通过”，也不会提高内容的实际正确率。正式交付应核对剧本、人物、商品、参考图和成片；一次通过率需要以实际测试统计衡量，不能保证任意模型、任意输入都不返工。

“系统提示词与自定义覆盖”用于高级调整。正常生产会自动更新，不需要每次点击“重新编译全部系统提示词”。只有剧本或资产被外部修改等维护场景才使用它。修改单项时，可用“系统编译稿”作为起点，切换“自定义填写”后“保存并应用”。

## 5. 新建项目与六种制作路径

点击顶部新建项目按钮，填写名称，选择起步内容、执行方式、剧本格式、带货方式和视频制作模式，再“创建项目”。已有项目可从“调整制作策略”进入“确认项目制作策略”，修改后“确认并应用”。

### 起步内容、格式与原稿处理

“AI 生成”适合从需求开始写作，可选“完整制作稿”“简易对白稿”“秒级分镜成片稿”。不确定格式时先下载相应示例。

“自己输入/上传”适合已有剧本，系统识别原稿格式并按对白和动作安排时长。“尊重原稿”用于尽量保持既有内容；“智能优化”允许整理提升；“重新创作”允许较大改写。上传后先检查人物、对白和结局，再继续制作。

“分步制作”让您逐阶段处理；“AI 一键制作”串联执行，但仍会在全部提示词确认等需要人工决策的位置等待。

### 视频制作模式对照

| 模式 | 实际流程 | 使用时要检查 |
| --- | --- | --- |
| 资产直投（无分镜图） | 确认人物、场景、物品/商品等参考资产后直接制作视频 | 参考列表齐全，商品原图包含在需要它的镜头中 |
| 首尾帧模式 | 每镜使用独立首帧与尾帧 | 首尾人物、位置、动作衔接正确 |
| 视频延续模式 | 第1镜首尾帧；第2镜起使用尾帧并串行引用上一镜完整视频 | 前镜成功后才能续接；串行等待属于依赖关系 |
| 智能首尾帧+视频延续 | 同场景续接，切场景使用首尾帧 | 场景边界正确，切场不误带上一镜视频 |
| 逐秒分镜合图 | 每镜按时间轴生成多画格合图，再制作视频 | 画格顺序与秒级动作一致，每格构图完整 |
| Codex 资产包直抽 | 导入合格 .pdramapack，使用包内提示词及图片引用 | 是独立导入入口；不是普通“资产直投”的别名 |

“Codex 资产包直抽”通过顶部“导入资产包”创建，不是新建普通项目时随意勾选的选项。软件先校验包；提示词与图片顺序锁定，不参考音频、不生成分镜图。缺少文件或校验失败时应修正资产包再导入。

## 6. 带货项目怎么填写

1. 选择“自然植入”或“明确带货”；纯故事选择“不带货”。
2. 上传真实商品原图，在“商品名称”填写对应商品。
3. 在“商品卖点”填写真实资料和使用场景。可留空，由 AI 根据名称判断日常卖点；这不等于 AI 可以编造功效、材质检测、认证、价格或活动。
4. 按真实情况填写“商品价格”“促销活动”“购买指令”。没有活动写“无促销”，购买指令也应与您的实际渠道相符。
5. 在剧情需求中写明人物为什么会使用商品、商品怎样推动解决眼前的问题，避免只要求“多展示商品”。
6. 生成后检查商品是否和人物动作、故事因果结合；不能出现脱离人物和剧情的单独产品广告镜头。

参考案例用于提炼“剧情需求 → 人物使用 → 效果反馈 → 剧情推进”的写作逻辑，不会把19个带货案例全文一股脑传入每个任务。没有带货内容的案例不用于提炼带货方法。选择带货并填写当前商品资料，也授权在保留上传原文的基础上生成独立执行稿，补齐必要的商品介绍和购买引导。有效带货时长由 Agent 标明实际介绍、使用展示、选购理由、优惠或购买引导的具体时段，再合并计算重叠区间；背景露出不计。暂以参考文本估算的 5.7% 为底线，并非对参考视频的实测值。

### 可复制的需求示例

> 商品：带提手收纳箱。原图：已上传。真实卖点：请填写经确认的容量、尺寸、材质与使用方式；无资料的项目不写具体数值。价格与活动：按实际填写。剧情：一家人搬家，父亲坚持丢掉旧物，女儿在整理时发现父亲保存的旧信，误会逐步解开。让收纳箱在人物整理、交接旧物时自然使用，不拍单独产品展示镜头。三名主要人物，结尾温暖。必须先给我完整剧本和全部提示词确认，再进入生成。

这是一段写法示例，不是对某款商品性能的事实描述。若对人物数量、必须保留的台词、结局有硬性要求，请直接写在需求中。

## 7. Agent 模式完整使用流程

### 第一步：写剧本或导入剧本

在“剧本与商品”准备商品资料与剧情需求，再使用写作或“生成并自动生产”入口。已有剧本使用上传入口或正文编辑区。需要保留核心改写时，使用“上传剧本并保留核心改写”，先预览再保存新项目。

完成后应看到完整剧本正文。核对角色名字、人物关系、对白归属、动作先后、故事结局以及商品资料。如果正文已保存但显示“待审核修订”，应处理列出的具体问题，不要再次点击新建或从头写作。

### 第二步：确认后续全部生成提示词

出现“确认后续全部生成提示词”时，先看总数，再按“人物”“场景”“物品 / 商品”“分镜合图”“分镜视频”分类浏览。搜索框可按名称、镜头或内容查找。

逐项检查：人物数量和身份；场景关系；动作因果和秒级顺序；说话人及完整对白；实际参考资产，尤其是商品原图；商品和人物互动是否成立。

英文执行稿会显示可编辑的中文查看稿；可展开“查看当前完整英文执行稿”。中文与英文长度不同是正常的。修改中文后确认，系统会更新相应英文执行文本；未修改且可复用的已批准执行稿不必重新调用模型编译。

单条用“保存并确认本条”或“保存中文并重编译英文”；全部核对后用“一键保存并确认全部”。确认前不要认为模型生成的审核意见代替了您的人工确认。

“稍后确认”只是关闭窗口。通过“继续确认全部提示词”悬浮按钮或提示词状态区重新打开。长文本在框内滚动；外侧滚动用于切换卡片。关闭软件前请保存尚未提交的编辑内容。

### 第三步：人物、场景、道具和商品资产

进入“角色与场景”，检查人物、服装、商品、道具和场景清单。每项可以按界面提供的入口生成、上传或复用已有资产。商品使用真实原图。

打开图片查看细节，不只看缩略图。人物要一致；道具要与剧情对应；商品包装、外观不能被替换。选中确认采用的结果后再继续。已存在的合格资产可复用，避免重复生成。

需要音色参考时，在音色库导入或绑定并试听；如果当前视频策略是“仅参考图 · 不传音频”，不要误以为绑定音色一定会上传到视频请求。

### 第四步：分镜图或直接制作视频

需要分镜图的模式，在“分镜工作台”检查首尾帧或合图，再确认采用的结果。资产直投和资产包直抽跳过此阶段是正常流程，不是漏生成。

生成分镜视频前，核对镜头提示词和实际参考列表。视频延续按前后依赖顺序进行，前一镜未完成时后一镜等待，不要为消除等待重复提交。

### 第五步：分镜视频验收

在“分镜视频”逐镜播放，检查人物、商品、台词、口型、动作顺序、画面衔接与声音。请求提交成功不等于视频已生成；远端完成也要等结果下载和入库后才能正常使用。

某一镜失败，先看它的任务详情和原始错误，再恢复或重试该镜。优先保留其他已完成镜头和可用资产。修改前镜可能影响依赖它的续接镜头，需要重新检查受影响范围。

### 第六步：粗剪与剪映草稿

所有需要的分镜确认后进入“智能粗剪”，生成粗剪并播放检查。可用“打开成片”预览、“定位到本地”查看文件。

在后期区域导出剪映草稿。音效、环境音、字幕等按导出选项组织为可编辑轨道；粗剪预览与剪映最终工程不是同一个交付物。打开草稿后再次检查字幕、声音和切点，再在剪映中按您的需求完成最终导出。

## 8. 简易模式详细使用

简易模式适合已经清楚每个镜头怎么拍的人，不负责替您完成剧本创作。

1. 进入“设置与连接”：点击“检测视频连接”，检查授权并发和默认画幅，点击“保存设置”。并发显示“未知”时使用“重新读取授权并发”；它不是0，也不是无限。
2. 新建项目，准备人物、场景、道具、商品。可上传、复用共享资产或使用图片生成入口。商品必须提供真实参考图。
3. 进入分镜区，点击“新建分镜”，选择场景和人物，填写画面动作、时长和对白。对白按“人物名（语气）：对白”逐行填写，例如“女儿（轻声）：这些信，你一直留着？”
4. 点击“保存修改”，再“生成全部提示词”。本模式按您给定的动作、对白和时间直接编译，不调用文本模型替您写作。
5. 检查并确认全部提示词，再“生成全部分镜合图”。检查图片后生成本镜或全部分镜视频。
6. 提交前读清确认框列出的依赖范围与可能产生的费用。长任务可“转入后台”，到“更多 → 任务与费用”查看。
7. 视频完成后进入“粗剪与剪映”，制作粗剪并导出可编辑草稿。

想从一句话写剧本或自动拆稿，请切到 Agent 模式；在简易模式等待文本 Agent 开始写作不会实现这一目的。

## 9. 历史项目、任务、费用与恢复

**找项目：** 顶部“当前项目”下拉框选择历史项目。先确认当前工作模式。已删除项目用“恢复项目”打开“项目回收区”，选择后“恢复所选项目”。

**找任务：** Agent 模式右侧“生产任务队列”“运行详情”“生产任务历史”显示本项目任务；本地 Agent 的任务及取消入口在设置面板内。简易模式到“更多 → 任务与费用”。

**找文件：** 资产预览提供“打开文件位置”，成片提供“定位到本地”。项目与素材总目录在设置中查看，不要凭安装目录推断数据目录。

**找消费：** 查看“计费明细”和对应任务结果。外部 Agent 账号额度与纯梦图片、视频费用分别计算。重复点击重做可能发起新请求，先确认旧任务是否仍在进行或已有结果。

**恢复生产：** 按状态区提供的继续、恢复或审核修订入口处理。正文和断点保留不等于后台仍在执行；判断是否运行应结合当前状态、任务详情、更新时间和明确错误。

## 10. 常见问题：现象、原因、操作

| 现象 | 常见原因 | 正确处理 |
| --- | --- | --- |
| 本地 Agent 连接失败 | 路径错误、未登录、CLI 不可用，或 MCP 工作端未接管 | 核对接入方式和路径；完成登录；MCP 模式重新加载配置并执行接管指令 |
| 原软件有新模型，这里没有 | CLI 清单与桌面清单不同、本地缓存未更新、账号权限不同 | 更新 Agent、刷新清单、检查来源；只使用已确认可接受的精确 ID |
| 已保存剧本但流程停住 | 待人工提示词确认或审核修订，也可能有明确任务错误 | 看状态区；打开完整确认窗口或处理具体审核项，不从头重复生成 |
| JSON 不匹配 | 输出被截断或模型返回了不符合当前阶段结构的内容 | 查看任务错误和已保留原文；核对模型及输出上限，再从断点恢复 |
| 提示额度、余额或频率限制 | 对应服务账号限制 | 检查实际使用的 Agent / API 账号，解决额度或频率问题后恢复 |
| AG 等待较长 | 模型仍运行，或原生单次等待已返回但会话尚未完成 | 看本软件任务详情；新版继续跟踪同一会话，不重复提交 |
| 文本正常但没有图片 | 工作端无生图工具，或图片来源未配置成功 | 验证真实图片能力，或明确选用已配置好的内置图片 API |
| 找不到历史项目 | 工作模式不同、保存目录不同、项目被删除 | 切回原模式，查看保存目录，检查项目回收区 |
| 商品原图未进入参考列表 | 原图未上传、未绑定到当前商品或镜头引用有误 | 回到商品资产核对原图，再检查受影响镜头的提示词与引用，确认后继续 |
| 某一续接镜头一直等待 | 上一镜仍运行、失败或尚未下载入库 | 先处理上一镜，不把正常串行依赖误当作 Agent 超时 |
| 提示词窗口卡顿、按钮被裁切 | 旧界面重复重建长列表、卡片底部宽度约束不合理 | 0.16.244 修复这两处；任务结束并保存后更新，未更新的窗口不会自动换代码 |
| 总确认后再次要求确认 | 剧本、资产或提示词改变使相关确认失效 | 核对改动涉及的条目，重新确认对应内容，不直接假定重复收费 |

反馈问题时提供：软件版本、工作模式、项目名称或 ID、出错阶段、发生时间、完整错误与任务状态截图。不要发送授权码、API Key 或登录凭据。

## 11. 开始正式制作前的核对表

- 项目创建在正确的工作模式，制作策略已确认。
- 五个 Agent 阶段的来源、模型和路径已保存；需要生图的阶段已验证真实图片输出。
- 商品原图和名称对应，卖点、价格、活动真实。
- 完整剧本的角色、对白、因果和结局已核对。
- 全部提示词及参考资产已人工确认，尤其检查商品、人物数量和动作先后。
- 视频来源、画幅、分辨率、音频参考策略与项目一致。
- 看过本次提交范围及费用，知道在哪里查看任务与恢复断点。
- 成片已实际播放检查，剪映草稿也已打开核验；不把“已提交”作为“已交付”。
