# 纯梦短剧老虎机 0.16.113

## 本地根修复版

- 对白只保留一个不可变事实账本：镜头、Foundry 制作 IR、中文确认稿和英文 H3 执行稿都从同一逐句账本编译，不再各自猜测说话人或沿用旧镜头副本。
- 上传或生成剧本中遗漏到人物表的真实说话人会按原稿确定性补回人物资产；对白原文、顺序、说话人、听者和语气均保留来源编号。
- 提示词预览会先核对当前镜头与旧 IR 的对白签名；旧 IR 失效时自动使用当前已绑定事实，不会把“崔钟”等说话人显示出来却丢掉其台词。
- 每个分镜视频提示词新增上一镜结束状态到本镜开场状态的承接合同；同场景继承站位、朝向、视线、服装、道具归属和情绪余波，换场必须带剧情动机。
- “分析剧本”和“生成完整剧本”两个独立入口与一键流程统一进入资产前提示词确认门：人物、场景、物品/商品、分镜合图和分镜视频全部生成提示词后先弹总窗，未确认不会提交付费资产。
- 单镜提示词窗口完整显示不可裁切的中文提示词，并在上方逐句显示说话人、听者、语气、原文和来源编号；长文本在窗口内部滚动，支持 100000 字符编辑。
- 提示词确认指纹只跟剧本与制作事实变化；任务进度、候选资产、抽卡和已选人物图不再误触发“提示词过期”。

## 模型边界

软件已保证提交给 H3 的对白原文、人物归属、参考素材顺序和跨镜承接来自同一事实源且可由用户逐项核对。H3 在收到正确输入后仍可能偶发不遵循口型、说话人、人物数量或运镜，这是生成模型的随机能力边界；软件不会把这种偶发不遵循伪装成对白账本或提示词已正确执行。
