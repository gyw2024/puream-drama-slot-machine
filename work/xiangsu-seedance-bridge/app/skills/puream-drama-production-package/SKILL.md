# PUREAM 短剧制作资产包

本技能采用用户2026-09-15明确批准的统一口径。开始前读取 references/unified-audit-policy.md 与 references/prompt-review-standard.md。用户当前指示及原始事实优先，旧示例与旧辅助脚本输出不能覆盖此口径。

## 输入与制作

1. 原创、上传、改写都先由Agent整理为逐镜标准执行稿：完整对白及说话人、身份、听者、语气情绪、动作因果、场景背景和必要资产。上传原件单独保留；带货模式且提供商品资料时，允许在独立执行稿中补齐已授权带货。没有商品的项目不强行带货。
2. 原创通常8–10分钟，允许合理略短略长；改写与原稿时长相差不超过30秒。无实际时长时由Agent估算原稿可演时长并标注依据。不得用静默、重复或慢读凑长。
3. 从源稿提取人物、场景、道具、服装、商品原图及集合成员关系，以稳定ID保存。保留用户原始描述、图片、物理身份和数量；视觉设计补充必须独立记录，不能编造商品事实。身份与瞬时站位、持有者、昼夜分开。
4. 先审核源头剧情、开场、完整对白链及带货，后由导演Agent给每个当前镜编写完整视频提示词。按用户要求每5镜一批并行，单镜只执行本镜剧本，补充必要身份、资产映射与只读邻镜边界。不得把邻镜对白或动作搬进当前镜。
5. 导演Agent安排精确可演时间轴、站位、视线、嘴部所有权和有动机的机位，不限定两句、两个人或两个机位。普通对白5–6有效中文字符/秒，强冲突至少8且清晰；连续真实无人说话不超过3秒。干净起音和完整收尾是要求，固定0.30/0.35秒只作建议。必要动作可与对白同步，不设固定静默预留。
6. 按实际海螺API及参考输入采用官方规范。视频保留完整对白一次、原始商品引用和清楚物理因果，不出现字幕、叠字、水印、额外人声、重复台词、串音或片头杂音。物体本来存在的印字保留；提示词英文描述可引用必要中文实物印字。参考式与首尾帧模式不得混用模板，不把应用自创英文句子当官方硬格式。
7. 带货提炼参考案例逻辑，结合人物需求、正常用途或真实卖点、实际价格活动与购买入口。不编造真实交易条件或功效；测试模拟数据明确标注。角色使用或持有的有动机特写允许，独立产品广告镜头禁止。有效带货由Agent标出准确子区间，程序只算并集。5.7%为参考文本估算的暂定基线，不是视频测量结果。
8. 资产先审核提示词，再在授权范围内生成并打开图片核验。需要角色视图、场景视图或道具图时按实际资产用途制作；图片未核验不得宣称合格，四视图素材不能变成正片四宫格。纯文本或生图前测试不得越界生成媒体。

## 审核、修复和缓存

- 源头、资产、单镜执行、全片实际视频提示词对白链分别由Agent审核。事实与用户要求高于任何派生计划和旧通过结论。作者可提交证据申诉，不能自评清空问题，必须独立裁决。
- 明确缺陷、通过、证据不足、未验证和有依据不适用分别保存；证据不足不改成错误，也不伪装通过。无需相邻镜的全片首尾边界不构成缺项。
- 每条发现保留位置、源头事实、当前内容和证据。先判断应改源稿还是下游，修正实际受影响部分并复核必要依赖，保留已通过的其他内容。不得仅手改一个测试项目冒充共用问题已解决。
- 不限制Agent运行时长或规定最多两轮；原输入和证据完全相同而无有效进展时，先诊断，不反复付费重试。账户/网络故障保存断点，余额不足不当作提示词过长；恢复后继续未完成部分。取消立即停止新增提交。
- 审核收据绑定源稿、提示词、引用、当前统一规则和审核模型配置。变化只失效有关依赖；旧标准的收据不能冒充新审核。保留原始响应及完整且来源匹配的部分交付，不推测截断字段。
- 软件只检查协议、ID、文件、持久化、引用归属和供应商实际限制；语义判断由Agent执行。旧脚本的措辞、字数、静默预留等测量只作证据，不具有内容否决或内容批准权。

## 打包、导入、媒体与交付

- 按references中的包结构保存源稿、资产、顺序、精确videoPromptEn、双语显示稿和引用清单。独立production_package模式保留其身份，不能伪装成asset_direct或首尾帧模式。实际API模式从真实输入推导。没有音频输入不能写Audio引用；不把一个图重复冒充首帧和尾帧。
- 导入前在隔离store调用真实应用导入接口，核对包与应用的ID、引用、对白顺序和提示词字节一致。辅助脚本应同步版本，不靠修改原稿或补写通过收据绕过接口。
- 提交的必须是用户看到并确认的同版内容。确认后实质变化返回相应审核与确认，不在发送时偷偷改写。稳定任务ID用于不确定提交的查询和去重，一次授权抽卡只产生一个上游任务。媒体重生仅依用户授权和已定位实际问题。
- 文本通过不能证明实际视频合格；实际媒体独立核验对白完整、语速、间隔、稳定声音、嘴型归属、杂音、动作、开场、字幕和参考一致性。只有文件存在、成功解码、API成功或剪映索引存在不能冒充媒体验收。缺媒体证据明确标未验证。
- 剪映草稿不自动建字幕轨，保留原始素材及账务。交付项目、素材与逐项证据，区分源码修改、离线测试、真实Agent、真实媒体、安装生效及发布。不能声称所有未来输入永不出错或无样本支持的95%通过率。
