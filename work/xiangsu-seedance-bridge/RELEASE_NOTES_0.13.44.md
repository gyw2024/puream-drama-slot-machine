# 0.13.44

- 每次重新点击“一键生成 10 个选题”都会创建新的逻辑请求，上一批题材进入禁用集；云端若仍重复则确定性切换到不同的本地完整批次。
- 三种剧本格式的查看/下载案例全部升级为 420 秒、42 单元的完整七分钟剧本，不再提供会误导用户的短片段。
- 上传稿把人物介绍、人物小传、故事简介与正式剧情分流：前者只建人物和背景资产，绝不生成成片镜头。
- 删除成片拼接器主动烧录文字的 `drawtext` 链路；所有模式继续硬锁无字幕、无标题、无水印、无背景音乐。
- 人物合板、三视图和介绍图统一固定为纯色 `#D9D9D9` 全画布背景，禁止渐变、烟雾、云纹、暗角、黑边和不同色块。
- 安装器改为可选择安装目录；设置页新增项目与素材保存位置，可完整复制现有项目后重启切换，旧目录始终保留。
