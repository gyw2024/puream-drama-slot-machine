# 纯梦短剧老虎机 v0.15.0

发布日期：2026-08-15

## 本次架构升级

- 保留现有界面、按钮、八种生产模式、一键做剧和分步做剧入口；底层统一由全局制作 Agent 调度文本、图片、视频提交和视频查询能力。
- 新增导演 Agent 原子镜头合同：一次供应商视频任务只能有一个机位主体、一个嘴型主体和一名说话人；说话人变化就是任务边界，生成后按原剧本精确时长硬切合成。
- 分镜合图会先生成“原子镜头画格表”，每个画格明确 `cameraOwner`、`mouthOwner`、`speaker`；换人秒点强制反打到新说话人，上一人立即闭口。
- H3 提示词按官方六段式生成，每个原子镜头只引用本镜人物、专属分镜画格和唯一音色；中文只保留在 `<d>[Chinese] ...</d>` 对话块，1900 字符预算在付费前验证。
- 人物表演不再只写抽象情绪。导演 Agent 输出必须同时包含表情、肢体、呼吸、音量、语速和重音，缺一项就自动修复，连续三次仍不合格则保留断点并停止付费生成。
- 整片开拍前完成所有镜头计划、分镜裁切、音色绑定和最终提示词预检；任何后镜不合格都会在第一笔视频费用发生前停止。
- 创意 AI 失败时不再用本地固定剧情、固定对白、固定资产或固定分镜替代。系统保留已成功片段和失败位置，继续任务只恢复失败的 Agent 单元。

## 始终有效的输出合同

- 严禁字幕、标题、姓名条、价格字、水印、界面文字、人物介绍、故事简介和资产板进入成片。
- 严禁背景音乐；只允许剧中对白、连续环境声和画面中真实发生的同步动作声。
- 用户上传对白逐字、逐句、顺序和说话人保持不变；Agent 只负责把任意格式转成可生产结构并补足表演、调度和镜头控制。
- 原有项目、历史候选、费用账本、远端任务、独立资产库及用户手动提示词均保留。

## 兼容与说明

- v0.15.0 会使旧的 H3 多说话人父镜头计划自动失效并由导演 Agent 重新编排，不复用旧错误提示词。
- 用户手动视频提示词仍按原功能原样提交；选择系统提示词时才使用导演 Agent 原子镜头合同。
- 本次验证不主动提交付费图片或视频任务；正式生成仍以用户点击或显式继续任务为准。
