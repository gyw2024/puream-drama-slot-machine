# 审核门控清单

版本：0.16.19（本轮候选）

本文只记录会让一键流程停止、回滚候选或触发自动返修的条件。判断原则是：主观创作质量必须由“审核蓝图”控制；文件、账号、授权、任务状态和身份归属等生产安全条件不能被质量开关绕过。

## 已纳入审核蓝图

总开关为 `generation.qualityGatesEnabled`，模块开关为 `generation.qualityGateModules`。任一模块只有在总开关和自身模块同时开启时才会阻断。

| 条件 | 模块 | 关闭后的行为 |
| --- | --- | --- |
| 选题重复、新颖性、人物关系多样性 | `script` | 保留 10 项结构完整选题；不因重复标题或关系单一停止 |
| 故事圣经评分、蓝图语义评分、对白/情绪/因果/反转/视觉/声音等创作评分 | `script` + blueprint detail | 记录为提醒，不回滚、不返修、不阻断 |
| 生产结构：主反转位置、商品出现窗口、商品因果链、开场结构 | `script` + `blueprintAuditChecks.productionStructure` | 保留原稿继续生产；可在开启后人工或 AI 修复 |
| 已保存旧断点的主反转位置预检 | `script` + `productionStructure` | 审核关闭时直接继续旧断点；开启时在再次付费请求前本地拦截 |
| 上传剧本的参考片规格建议 | `script` | 只保存建议，不改写用户原稿、不阻断拆镜 |
| 场景四视图、人物身份图、人物视频首帧等资产质量 | `assets` | 生成结果直接选中；不跑 FFmpeg 质量审查 |
| 分镜首尾帧/逐秒合图质量 | `storyboards` | 生成结果直接选中；不因画面审查失败重抽 |
| 分镜视频音画、重复画面、字幕/画布泄漏等技术与质量审查 | `videos` | 保留已下载视频并继续；不因质量失败重抽 |
| 成片音画、重复镜头、最终视觉质量 | `delivery` | 生成并交付成片；不执行最终质量审查 |

## 不属于审核蓝图的生产硬条件

这些条件不是“好不好看”的判断，而是保证任务能提交、费用可控、参考不串项目、身份和音色不串人的必要条件。它们保持阻断行为：

- API Key、模型名、Base URL、供应商能力与项目 engine 对齐。
- 账号授权、余额、许可证和每日额度。
- 用户主动暂停/停止、账号切换、任务控制信号。
- 项目模式已确认；剧本已生成或上传；上传剧本已完成结构化；分镜数组非空。
- 本地文件存在、可读取、非空；FFmpeg 存在；远端下载内容确实写入本地。
- 分镜所需首帧、尾帧、逐秒合图、场景、人物、商品和上一镜视频等参考缺失。
- 参考图路径在当前项目内，候选属于当前 `productionRevision`，禁止跨项目或历史版本串用。
- 视频供应商/项目 engine、参考图数量、音频数量、时长和 API 模式符合上游协议。
- 人物身份图、说话人、听者、对白、mouth owner、音色文件的唯一绑定；禁止 A 人说 B 话、重复音色或错误角色资产。
- H3/视频提示词的结构完整性：逐句对白、speaker/listener/voice/reference 绑定、中文对白、无字幕、无 BGM 等上游必需合同。
- 上传剧本来源对白和场景与 AI 结构化结果的逐句/逐场景保真校验。
- 视频提交幂等键、taskId 保存、远端 pending/暂停恢复和禁止重复付费提交。
- 成片拼接输入存在、所有分镜视频齐全、拼接期间输入指纹未变化、输出文件成功写入。

## 本轮已修复的漏网条件

1. `generateCompleteScript()` 的旧断点主反转预检此前无条件执行；现在仅在 `productionStructure` 审核明细开启时执行。
2. `stitchProject()` 的分镜技术审查此前挂在 `delivery` 模块；现在明确挂在 `videos` 模块，成片审查仍由 `delivery` 控制。
3. `generateShotVideo()` 的 FFmpeg 技术审查此前可能在视频模块关闭时执行；现在仅在 `videos` 模块开启且请求允许审查时执行。
4. 选题重复/关系多样性此前会在审核关闭时阻断；现在只保留 10 项结构合同。

## 代码入口

- 总开关与模块判断：`app/workbench-workflow.js:isQualityGatesEnabled()`、`qualityGatesEnabled()`。
- 剧本审核映射：`scriptQualityGateOptions()`、`activeBlueprintFailures()`、`productionStructureGateEnabled()`。
- 候选确认：`app/workbench-store.js:confirmCandidate()`，仅总开关和对应模块均开启时检查 `qualityAudit`。
- 运行状态过滤：`app/workbench-status.js`，审核关闭时不把候选标为“质检失败/待质检”。

## 回归要求

- 审核关闭：所有质量模块不得阻断、回滚或自动返修；硬条件仍必须报错。
- 只开 `videos`：分镜技术审查运行，脚本/资产/分镜图/成片质量审查不运行。
- 只开 `delivery`：只运行成片审查，不运行分镜技术审查。
- 旧断点：`productionStructure=false` 可以继续；开启后非法断点必须在付费请求前停止。
