# 0.16.23

- 修复客户上传剧本时 AI 失败后被本地解析结果冒充“AI 拆镜成功”的问题；未拿到合格 AI 结构化结果时不再生成资产卡。
- 上传剧本必须经过文本模型结构化分析；模型返回时间段、镜号或制作标题作为场景时，Agent 会自动追加一次定向修复请求。
- `0-10秒`、`第18镜`、机位/景别等不再进入场景资产；`旧小区楼道（次日清晨）`会归并为唯一物理场景“旧小区楼道”。
- AI 或接口失败时保留可重试断点和原始剧本，明确显示“未写入本地兜底资产”；继续任务只重试失败片段，不重复请求已完成片段。
- 简易模式与 Agent 模式共用同一上传分析修复链，独立数据目录不受影响。
