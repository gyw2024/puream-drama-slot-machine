# 纯梦短剧老虎机 0.16.132

## 修复

- 修复导入 Codex 资产包后，参考图仍在上传时被项目页面刷新误判为“本地没有对应上游任务”的问题。
- 修复暂停恰好发生在上传完成与 HTTP 提交之间时，被错误记成“提交响应未知”的问题。
- 修复“每个分镜只生成一次”错误地按本地尝试次数锁死，导致尚未创建上游任务的分镜也无法继续的问题。
- 修复 Agent 调用边界丢失“确认未创建上游任务”证据，造成暂停状态无法正确落盘的问题。

## 恢复与唯一性

- 上游状态细分为：未开始、准备中、确认未创建、响应未知、已创建。
- 确认未创建的任务可以安全继续；响应未知只允许使用原 `clientRequestId` / 幂等键找回同一任务。
- 已存在 taskId 或已生成结果的资产包分镜仍严格禁止第二次生成。
- 0.16.131 误判为 `VIDEO_JOB_ABANDONED` 的短时任务会迁移为可恢复状态，不再显示成不可处理的红色失败。

## 用户界面

- 资产包分镜按钮显示真实状态：`抽卡：本镜视频（仅一次）`、`继续原任务 · 不会重抽` 或 `已生成一次 · 不可重抽`。
- 可恢复的暂停任务不再伪装成云端生成失败；说明中明确是否创建上游任务、是否扣费以及下一步。

## 安全边界

- 本次回归和安装验收禁止调用真实 H3 生成接口，不新增视频任务、不产生视频费用。
