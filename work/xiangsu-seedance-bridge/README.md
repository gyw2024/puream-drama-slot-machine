# 纯梦短剧老虎机 0.13.22

Windows 桌面短剧生产工作台。支持从 AI 选题与完整剧本一路生成资产、分镜图、分镜视频和成片，也支持在每个环节使用用户自己的文件。

## 当前能力

- 一键生成选题：桌面端只发一次请求，官网中继立即返回 SSE 状态帧并持续发送心跳，长推理不会再因静默超时被错误中止。
- 五分钟剧本通道：先锁定故事圣经，再并行生成分镜规划和正式单元，完成后执行本地生产合同审计并进入资产阶段。
- 上传台词事实锁：支持“说话人（语气/动作）：说话内容”的极简台本；系统先判断故事，再生成资产、分镜图和视频提示词，原稿每句话、说话人和语气会按不可改写账本逐句校验。
- 两套视频逻辑：本地像塑与纯梦云端算力分别编译自己的提示词和参考素材合同；云端提示词强制包含说话人、听话人、情绪语气、原句对白、对方反应与声音要求。
- 八模式制作矩阵：本地像塑/纯梦云端分别适配首尾帧、视频延续、智能模式和逐秒分镜合图；一键制作与分阶段制作共用同一份帧、台词、商品和提交合同。
- 商品语义绑定：剧本提到商品或同品类物件时，自动匹配用户上传的商品名称、说明、卖点与商品图；无剧情触发时不会硬塞商品。
- 全流程手动入口：上传剧本、商品图、人物/服装/道具/场景图、人物视频与音色、分镜图、分镜提示词、分镜视频和完整成片。
- 独立资产库：直接保存人物图、场景图、通用图片、资产视频和资产音频，并可绑定到当前项目。
- 多项目并发：不同项目可同时运行；同一项目会阻止重叠操作，切换项目不会中断后台任务。
- 可恢复历史：项目删除后进入本机回收区；索引或项目文件损坏时优先从有效备份恢复，无法恢复的目录仍会以“受损项目”保留在列表中。
- 任务安全：逐秒合图模式不生成、不校验尾帧；分镜视频只在用户明确点击后提交，重启仅同步已有上游任务，不会自动新建付费任务。
- 存储可选：云端参考素材默认由纯梦托管，也可在系统设置中切换到用户自己的阿里云 OSS；OSS 配置会加密保存并在重启后恢复。云端生成结果仍按上游返回地址下载到本地，不把“参考素材直传 OSS”误报成“全部结果已归档 OSS”。

五分钟是快速路径的产品目标，不是对第三方模型响应时间的绝对保证。实际耗时仍受所选文本模型和官网上游负载影响；每次完成会把真实耗时记录到 `script.generationPerformance`。

## 开发与构建

要求：Windows、Node.js、npm。

```powershell
npm.cmd install
npm.cmd run prepare:build-assets
npm.cmd run verify:build-assets
npm.cmd test
npm.cmd run build:dir
npm.cmd run audit:packaged
npm.cmd run build:installer
```

`prepare:build-assets` 从固定的 FFmpeg 7.1 Release 下载构建资产，并在复制前后校验目标二进制的大小与 SHA-256；详细清单见 [BUILD_ASSETS.md](BUILD_ASSETS.md)。

安装包输出到 `dist-fixed-0.13.22`。`audit:packaged` 在隔离用户数据目录中后台启动打包态应用，审查多尺寸布局、生产阶段、主要弹窗、默认云端配置、手动切换、敏感模型名可见性和 WCAG 严重问题；不会提交任何生成任务。

## 数据与安全

- 用户项目与设置保存在 Electron `userData\workbench`，覆盖安装不会删除。
- 授权与供应商凭据通过 Electron `safeStorage` 保存，不写入 Git；安全存储不可用时拒绝明文落盘。
- 生成任务保留成本账本、上游回执、断点与失败原文；已付费结果解析失败时不会自动重复提交。
- 远程媒体采用流式下载、重定向后重新校验公网 HTTPS 目标，并设置体积上限。
- 安装包、用户项目、生成视频、`node_modules` 和 FFmpeg 二进制不进入 Git 历史。

## 目录

- `app/`：Electron 主进程、工作流、存储、渲染界面与本地原生助手。
- `plugin/`：本地像塑桥接插件源码。
- `scripts/`：回归、构建资产校验和安装包审查脚本。
