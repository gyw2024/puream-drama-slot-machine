# Seedance Mini 生成器

本机桌面应用，通过安装在像塑中的只读会话桥复用当前登录态，调用像塑的 `SD_2.0_MINI` 视频生成能力。

安全边界：

- 不要求、显示或导出 API Key、Cookie、Token、动态签名。
- 桥接服务只监听 `127.0.0.1:28911`，并使用本机随机令牌鉴权。
- 只允许调用固定的 Seedance 2.0 Mini 任务接口；不绕过账号额度、内容审核或权限。
- 像塑更新后，内部模块名称或协议可能变化，需要重新兼容。

当前版本先完成本机桥接与能力检测。像塑重启加载插件后，通过“检测能力”读取函数形状，再绑定上传、提交、查询与下载协议。
