# 纯梦短剧老虎机 0.4.0

面向写实真人短剧/漫剧的本地制片工作台。应用接收一份完整剧本，建立人物、场景、商品和镜头资产，调用 PUREAM 官网中转的文本/图片/可选数字人视频能力，并复用本机像塑登录态调用 Seedance 2.0 Mini 生产分镜视频，最后按镜号拼接完整成片。

## 默认接口与安全边界

- 文本：`https://puream.cn/api/desktop/chat/models` 和 `/api/desktop/chat/complete`，自动选择官网当前首个可用模型，复用纯梦大助手管理员授权。
- 生图：`https://puream.cn/api/ai/gpt-image-2/v1/images/generations` 和 `/tasks/{taskId}`，异步提交、轮询并下载结果。
- 单人数字资产视频（可选）：PUREAM 官网 Grok 或 Gemini 视频中转；默认仍使用 Seedance 2.0 Mini。
- 分镜视频：本机像塑登录态桥接 `Seedance 2.0 Mini`，无需火山方舟 API Key。
- 授权码从纯梦大助手已有配置自动导入，使用 Electron `safeStorage` 加密保存。应用不会读取、保存或显示任何上游供应商 Key。
- 默认配置和界面不提供绕过 PUREAM 官网直接调用外部文本/图片/Grok/Gemini 上游的入口。

## 生产流程

1. 粘贴完整短剧剧本，上传商品图，填写商品名称与卖点。
2. PUREAM 文本中转按段完成导演级拆解：故事结构、角色圣经、场景圣经、原片/叙事动作拍点、5–10 秒生成单元、单元内多个 `subshots`、对白、表演、声音、首尾状态及商品锚点。
3. 生成或上传角色三视图、人物介绍图、场景空镜和分镜首尾帧；每次生成是一张候选卡。
4. 生成角色独白视频，从中提取单声道 WAV 音色；每位角色最多提取 5 秒，三位角色合计正好不超过 15 秒。
5. 选择延续模式或首尾帧模式生成每个分镜视频。
6. 所有分镜选择版本后按镜号拼接，优先无损合并，格式不一致时统一转码。

各环节均可单独使用。候选历史只有在用户明确“选中此卡”并确认后才清理同对象、同阶段的其他版本。

## Seedance 2.0 Mini 硬限制

- 图片：0–9 张。
- 视频：0–1 个，最长 10 秒。
- 音频：0–3 段，合计最长 15 秒。
- 时长：5–10 秒整数；工作台默认 5 秒或 10 秒。
- 画幅：`9:16`、`16:9`、`4:3`、`1:1`、`3:4`、`21:9`。
- 视频并发：全局设计上限 5；延续模式严格串行，首尾帧模式可选 1–5 路并发。

素材顺序会写入最终提示词：`图1…图9`、`视频1`、`音频1…音频3`。商品出现单元优先注入用户上传的商品图；人物音色按角色顺序映射。媒体上传前在本地再次校验数量、格式、时长和画幅，不依赖界面校验。

## 两种视频模式

- 延续模式：严格串行。第一单元由首帧建立基准，第二单元开始把上一单元完整视频作为 `视频1`，只从最后一帧继续。最后 0.5 秒保留稳定尾帧。
- 首尾帧模式：每个生成单元使用自己的首帧和尾帧，可 1–5 路并发。提示词要求从图1真实运动到图2，不用溶解、人物变形或无动机闪白替代动作与剪辑。

一个生成单元可以包含多个原片分镜头。系统用 `subshots` 按 0–2 秒、2–5 秒等时间段写景别、机位、动作、对白、声音和切换方式，同时保留原镜头层供追溯，不会因为合并生成而丢失原片信息。

## PUREAM GPT Image 2 参考图说明

官网 GPT Image 2 当前只接收可公网访问的参考图 URL。由工作台通过 PUREAM 生成的资产会同时保留本地文件和官网结果 URL，可继续用于人物/场景/分镜参考；用户本地商品图即使没有公网 URL，仍会在最终 Seedance 视频生成时通过像塑原生上传链路作为商品参考图传入。
