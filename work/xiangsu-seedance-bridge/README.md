# 纯梦短剧老虎机 0.13.14

Windows 桌面短剧生产工作台。支持从 AI 选题与完整剧本一路生成资产、分镜图、分镜视频和成片，也支持在每个环节使用用户自己的文件。

## 当前能力

- 一键生成选题：桌面端只发一次请求，官网中继会立即返回 SSE 状态帧并持续发送心跳，长推理不再因 60 秒静默被错误中止。
- 五分钟剧本通道：故事圣经串行锁定；分镜规划和正式分镜分别并行生成；完成后执行本地完整生产合同审计并自动进入资产阶段。
- 两套视频逻辑：本地像塑与纯梦云端 H3 分别编译自己的提示词和参考素材合同，不共用一套视频提示词。
- 全流程手动入口：上传剧本、商品图、人物/服装/道具/场景图、人物视频与音色、分镜图、分镜提示词、分镜视频和完整成片。
- 独立资产库：直接保存人物图、场景图、通用图片、资产视频和资产音频，并可绑定到当前项目。
- 资产依赖保护：更换上游人物、场景、分镜或商品图后，相关旧资产会退出当前版本但保留历史。

五分钟是快速路径的产品目标。实际耗时仍受所选文本模型和官网上游负载影响；每次完成会把真实耗时记录到 `script.generationPerformance`。

## 开发

要求：Windows、Node.js、npm。

```powershell
npm.cmd install
npm.cmd test
npm.cmd run build:installer
```

`npm.cmd test` 当前覆盖选题 SSE、单请求中断处理、五分钟并行路径、各阶段手动入口、独立资产库及商品依赖失效。

安装包输出到 `dist-fixed-0.13.14`。打包前还需准备 `media-tools/ffmpeg.exe`；其固定版本、大小和 SHA-256 见 [BUILD_ASSETS.md](BUILD_ASSETS.md)。`node scripts/audit-packaged.js` 可对打包态程序做启动、布局与可访问性检查。

## 数据与安全

- 用户项目与设置保存在 Electron `userData\workbench`，覆盖安装不会删除。
- 授权与供应商凭据通过 Electron `safeStorage` 保存，不写入 Git。
- 生成任务保留成本账本、上游回执、断点与失败原文；已付费结果解析失败时不会自动重复提交。
- 安装包、用户项目、生成视频、`node_modules` 和 FFmpeg 二进制不进入 Git 历史。

## 目录

- `app/`：Electron 主进程、工作流、存储、渲染界面与本地原生助手。
- `plugin/`：本地像塑桥接插件源码。
- `scripts/`：当前版本回归与安装包审计脚本。
