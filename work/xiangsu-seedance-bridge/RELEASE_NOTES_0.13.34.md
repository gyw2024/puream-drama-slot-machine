# 纯梦短剧老虎机 0.13.34

发布日期：2026-08-14

## 本次升级

- 新增“上传对白稿并轻改”：支持 `A：内容 / B：内容`，自动重构人物名称、轻微调整措辞并补充少量衔接；故事事实、事件顺序、人物关系、结局、数字金额和商品出现节点保持不变，云端异常时自动用本地保真整理完成完整剧本。
- 重做按钮帮助：界面不再显示感叹号；鼠标移入或键盘聚焦按钮时直接显示对应作用。右侧任务栏改成两行八格，并分开显示真实运行状态和历史详情。
- 修复幽灵运行状态：界面以主进程真实操作和视频任务为准，应用重启后会清理遗留的运行标记，不再把历史状态显示成后端正在调用。
- 全局资产库覆盖人物、场景、道具、服装、商品、通用图片、资产视频、资产音频和人物音色；新项目可直接绑定，绑定时复制到项目，原资产和历史项目不被覆盖。
- 系统设置中的每一项提示词都显示准确的生效页面、所属模块、作用、输入与输出；查看/下载示例严格使用当前提示词键。
- 新增全流程下一步指引：根据当前项目状态提示并动态高亮应点击的按钮，上传剧本、对白稿、资产、分镜图、分镜视频和成片均有对应去向。
- 左下角固定显示版本和更新状态；发现新版后可在主进程下载、校验 SHA-256 并覆盖安装，项目与全局资产库不会删除。
