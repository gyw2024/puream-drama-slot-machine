# 纯梦短剧老虎机 0.13.21

## 本次修复

- 上传自然台本会先解析成不可改写的逐句事实账本，固定每句话的原文、说话人和原稿语气；AI 只补充听者、表情、动作、镜头和声音表演，系统随后按 ID 回填并校验。
- 人物资产提示词补充故事身份、情绪与表演作用；场景资产提示词补充剧情功能和商品使用空间；分镜图提示词明确每句台词对应的说话人、听者、语气、表情与身体状态。
- 本地像塑和纯梦云端视频提示词分别编译；上传台词必须在最终视频提示词中恰好出现一次，并绑定正确角色。云端中文台词仅进入 `<d>[Chinese]` 原文块。
- 新增八模式全局矩阵：本地像塑/纯梦云端分别覆盖首尾帧、视频延续、智能模式、逐秒分镜合图，统一约束帧需求、图像提示、视频提交与连续性。
- 一键制作和分阶段制作使用同一矩阵合同；逐秒分镜合图只使用合图，不再生成或校验尾帧。
- 根据剧情中的商品名称、同品类指代和使用动作，匹配用户上传的商品名称、说明、卖点与商品图；无关动作不会误触发商品植入。
- 长剧本最多拆为四个并行分析批次，每批最多八个生成单元；台词行不会从中间拆断。不同批次重复使用的局部人物/场景 ID 会在合并时统一重映射，避免说话人串位。

## 安全与兼容

- 手动视频提示词仍按用户原文直接提交；关闭蓝图审核后不恢复系统质量拦截。
- 新鲜安装仍默认使用纯梦云端算力，可手动切换本地像塑；用户可见全流程不显示内部模型代号。
- 本次回归使用本地 fixture 和模拟供应商响应，不提交图片、视频或文本付费生成任务。
