# 纯梦短剧老虎机 0.16.171

## 外部 Agent 接入

- 系统设置新增“连接电脑上的 Agent”区域，直接显示当前 MCP 服务状态、实际启动命令、参数以及通用 JSON、Codex TOML 两种配置。
- 支持一键复制命令、参数或完整配置，并提供真实 MCP 握手检测；不再让用户填写不存在的网址、端口、令牌或 API Key。
- 安装版使用独立解包的 stdio 启动入口，外部 Agent 通过 `纯梦短剧老虎机.exe --mcp-stdio` 建立标准输入输出连接。
- MCP 握手确认服务名、协议版本、工具清单和项目读取均可用；当前提供 35 个工具。

## 稳定性修复

- 修复安装版直接从 ASAR 内启动 MCP 脚本失败的问题。

- 用户数据安装前后审计改为复制数据库及 WAL/SHM 后在临时目录校验，不再直接打开客户正在使用的 SQLite 文件。
- 安装和更新保持原有项目、资产、设置与任务数据不变。
